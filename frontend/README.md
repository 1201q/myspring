# 지도 프런트엔드

Vite + React + TypeScript + MapLibre로 구현한 전국 인허가 지도입니다. 수집 대상 15개 업종의 유효 위치 3,782,478건을 제공합니다. 업종 선택 목록은 서버의 `/api/v1/map/categories`에서 받아옵니다. 데이터 범위와 API 계약은 [전국 지도 API](../docs/national-map-api.md)를 참고하세요.

## 실행

Node.js 24 LTS를 권장합니다. 프로젝트 루트에서 SSH 터널과 Spring Boot를 먼저 실행합니다.

```powershell
# 터미널 1: DB 접속 터널 (이미 실행 중이면 재실행하지 않습니다.)
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:15432:127.0.0.1:5432 coin

# 터미널 2: C:\projects\spring
.\gradlew.bat bootRun

# 터미널 3: C:\projects\spring
cd frontend
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 이후 의존성이 바뀌지 않았다면 `npm run dev`만 실행하면 됩니다.

Vite가 브라우저의 `/api` 요청을 `http://127.0.0.1:8080`으로 프록시합니다. 프런트엔드에 DB 비밀번호를 넣지 않습니다. 개발 서버는 로컬 루프백에서만 엽니다.

## 동작

- 지도 이동이 끝나면 현재 화면 범위로 `/api/v1/map/businesses?bbox=...&limit=500`을 요청합니다. 전체 페이지를 순회하지 않습니다.
- 200ms 대기와 이전 요청 취소를 적용합니다. 한 번에 최대 500건을 표시하고 잘린 경우 확대 안내를 제공합니다.
- `coordinateStatus=CONVERTED`이고 위경도가 유효한 자료만 마커로 표시합니다. 좌표 순서는 `[longitude, latitude]`입니다.
- 좌표가 없거나 좌표계가 미확인인 업종은 이 지도 조회에서 제외됩니다. 지도상의 개수는 전체 인허가 건수가 아닙니다.
- 상세 정보는 목록 API에 포함된 데이터를 사용합니다. 별도의 상세 API 요청은 하지 않습니다.
- 업종과 날짜 필터를 제공합니다. 날짜 해제 시 폐업 기록도 포함합니다. 과거 날짜의 존재 여부는 인허가일·폐업일로 추정하며 위치는 최신 원천 좌표 기준입니다.
- 넓은 화면에서는 확대 안내를 보여주고 조회하지 않습니다. 광역 집계·클러스터·자동 시간 재생은 후속 작업입니다.
- 지도 및 API 오류, 로딩, 빈 목록 안내를 제공합니다.
- 데이터 출처는 행정안전부 LOCALDATA, 배경 지도는 OpenStreetMap입니다. 외부 타일을 불러오므로 인터넷 연결이 필요합니다.

## 확인

```powershell
npm run build
```

화면에서 다음을 확인할 수 있습니다.

1. 지도를 이동하면 화면 범위의 목록과 마커가 갱신됩니다. 500건 한도 안내는 전체 건수가 아닙니다.
2. 마커를 누르면 해당 인허가 정보가 열립니다.
3. 목록에서 인허가를 누르면 해당 위치로 이동합니다.
4. 업종·날짜 선택과 날짜 해제가 조회 조건에 반영됩니다.
5. 상세 닫기가 동작하고 좁은 화면에서는 지도와 목록이 세로로 배치됩니다.
6. Spring을 실행하지 않았을 때 오류와 다시 불러오기 버튼이 보입니다.

마커가 겹치거나 현재 화면 밖에 있으면 눈으로 센 점의 수와 전체 마커 수가 다를 수 있습니다.

현재 자동 검증은 빌드·린트와 실제 프록시 API 요청까지 완료했습니다. 브라우저 자동화 호스트가 연결되지 않아 위 화면 조작 항목의 실제 렌더링은 직접 검증하지 못했습니다.

`npm run build`는 TypeScript 검사와 배포용 정적 파일 생성을 수행합니다. `dist`를 배포할 때는 운영 웹 서버에서도 `/api`를 Spring으로 전달해야 합니다. Vite 개발 프록시는 배포 파일에 포함되지 않습니다.

MapLibre worker는 Vite의 `?worker&url`로 번들링하여 개발 및 배포 환경에서 같은 출처로 로드합니다.
