# 지도 프런트엔드

Vite + React + TypeScript + MapLibre로 구현한 전국 인허가 지도입니다. 수집 대상 15개 업종의 유효 위치 3,782,478건을 제공합니다. 업종 선택 목록은 서버의 `/api/v1/map/categories`에서 받아옵니다. 데이터 범위와 API 계약은 [전국 지도 API](../docs/national-map-api.md)를 참고하세요.

## 실행

Node.js 24 LTS를 권장합니다. 프로젝트 루트에서 SSH 터널과 Spring Boot를 먼저 실행합니다.

```powershell
# 터미널 1: DB 접속 터널 (이미 실행 중이면 재실행하지 않습니다.)
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:15432:127.0.0.1:5432 coin

# 터미널 2: C:\projects\spring
.\gradlew.bat bootRun

# 터미널 3: C:\projects\spring
cd frontend
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 이후 의존성이 바뀌지 않았다면 `npm run dev`만 실행하면 됩니다.

Vite가 브라우저의 `/api` 요청을 `http://127.0.0.1:8080`으로 프록시합니다. 프런트엔드에 DB 비밀번호를 넣지 않습니다. 개발 서버는 로컬 루프백에서만 엽니다.

## 동작

- 페이지를 열면 서울 지역의 시간 지도를 바로 준비합니다. 별도의 기록 지도/지역 재생 전환은 없습니다.
- 하단에서 지역·업종, 1·3·12개월 또는 누적 기간, 선택 월, 재생 속도를 바꿀 수 있습니다. 업종 선택과 목록 재시도도 하단 컨트롤에 통합되어 있습니다.
- 선택한 지역의 바이너리만 받아 GPU에서 월·업종 조건을 적용합니다. 지도 이동·확대 때 이벤트 파일을 다시 조회하지 않습니다.
- 지역 전체 인허가·폐업 신고 집계와 업종 순위를 표시합니다. 누적은 영업 중인 사업장 수가 아닙니다.
- 점을 누르면 재생을 멈추고 상세 API로 사업장 정보를 표시합니다. 월·업종·지역을 바꾸면 이전 상세 요청을 취소하고 선택을 해제합니다.
- 화면 범위 목록 조회, 기본 사업장 PBF 레이어, 존재 여부 날짜 입력은 현재 화면에서 사용하지 않습니다. 배경 지도 타일은 계속 사용합니다.
- 지역별 다운로드 진행률, 오류·재시도, 라이트/다크 테마를 제공합니다.
- 좌표와 지역은 현재 주소 스냅샷 기준입니다. 원본 범위와 발행 방법은 [전국 시간 재생 안내](../docs/national-playback-implementation.md)를 참고하세요.

## 확인

```powershell
npm run build
npm run lint
node --test src/nationalPlaybackData.test.mjs
```

1. 첫 진입 시 별도 버튼 없이 지역 지도와 시간 컨트롤이 표시됩니다.
2. 지역·업종·월·기간 변경과 자동 재생/일시정지가 동작합니다.
3. 지도 점을 누르면 상세 정보가 열리고, 지도 확대·축소 중에도 선택이 유지됩니다.
4. 월·업종·지역을 바꾸면 이전 상세 선택이 해제됩니다.
5. 테마 전환, 상세 닫기, 다운로드 실패 시 다시 조회를 확인합니다.

`npm run build`는 TypeScript 검사와 배포용 정적 파일 생성을 수행합니다. `dist`를 배포할 때는 운영 웹 서버에서도 `/api`를 Spring으로 전달해야 합니다. Vite 개발 프록시는 배포 파일에 포함되지 않습니다.

MapLibre worker는 Vite의 `?worker&url`로 번들링하여 개발 및 배포 환경에서 같은 출처로 로드합니다.
