# 골목·발달 상권 길 레이어

구현일: 2026-11-23. 기존 주요상권 면 경계를 유지하고, 사용자 제공 오픈메이트 길단위 상권 자료(2023년 1분기)를 별도 레이어로 추가했다.

## 데이터와 재생성

- 17개 시도, 골목상권 45,973개 + 발달상권 66,865개 = 112,838개 도로 구간. 두 원본 모두 공란인 도로는 표시하지 않는다.
- 두 상품은 같은 도로망이며 분류 필드만 다르다. SHP 바이트 일치, DBF 행 식별자 일치, 분류 중복 없음, 투영 파라미터를 빌더에서 확인한다.
- 식별자는 `MEGA_CD:CTY_CD:RD_NM:ID`. ID 단독으로 연결하지 않는다.
- SHP/DBF를 읽어 WGS84 GeoJSON으로 변환한다. 원본은 변경하지 않는다. DBF는 EUC-KR이며 PRJ의 사용자 정의 TM 파라미터를 그대로 사용한다.
- PRJ의 datum이 unknown이므로 Bessel/Korean 1985로 해석하고, 기존 프로젝트에서 검증한 EPSG:5191과 동등한 datum 변환을 적용했다. 투영 자체를 EPSG:5191로 대체한 것은 아니다. 변환식은 생성 manifest에 기록한다. 소스 기관의 datum 명시와 측량 수준의 위치 정확도는 아직 확보하지 않았다.
- 산출물은 `frontend/public/data/commercial-roads/`에 시도별 17개 파일(전체 약 58MB)과 manifest로 보관한다. 파일 해시, 원본 SHP·두 DBF·PRJ 해시를 기록한다. 강원/전북은 원본의 42/45를 사용하며 전남광주 재생 지역에서는 29/46 두 파일을 합친다.

프로젝트 루트에서 재생성한다. 먼저 frontend 의존성을 설치해야 한다.

```powershell
node scripts/build-commercial-roads.mjs "C:\Users\1201q\OneDrive\Desktop\data"
```

상품 출처: [골목상권](https://www.bigdata-transportation.kr/frn/prdt/detail?prdtId=PRDTNUM_000000001010), [발달상권](https://www.bigdata-transportation.kr/frn/prdt/detail?prdtId=PRDTNUM_000000001013). 제공기관은 오픈메이트이며 기존 면 경계의 소상공인시장진흥공단과 구분한다. 공개 배포 이용 조건의 확인 상태는 기존 [자료 검토](commercial-road-theme-data-review.md)를 따른다.

## 화면과 집계

레이어 시트에서 ‘골목·발달 상권 길’을 켠다. 줌 13 이상에서 선택 시도의 파일을 불러오며 그 이하에서는 선을 숨긴다. 골목은 점선, 발달은 실선, 선택한 구간은 accent로 표시한다. 두 분류와 도로명을 정보 독에서 검색할 수 있고 지도와 목록 모두 선택 가능하다. 면과 길이 겹치는 곳에서는 길 클릭이 우선한다.

선택한 **개별 도로 구간**에서 직선거리 100m 이내의 개폐업을 현재 재생 데이터로 계산한다. 기간 양끝 포함, 선택 업종, 시군구 배정 마스크를 적용한다. 시군구 배정 준비 중에는 전체 지역의 숫자를 대신 보여주지 않는다. 동일 업소의 중복 개업/폐업 행은 각각 한 번 세며 두 종류의 기록이 있으면 양쪽에 센다. 목록에서는 한 업소로 합친다. 가까운 순으로 페이지당 10개를 표시하고, 업소를 누르면 기존 상세 팝업에 연결한다.

100m는 탐색용 규칙이다. 원천 상권 경계, 도보 거리, 해당 길의 독점적 점포 소속을 뜻하지 않는다. 여러 구간의 100m 범위가 겹칠 수 있으므로 구간별 수치를 더해 지역 합계를 만들 수 없다. 길 분류는 2023년 고정 자료이며 과거 재생 당시의 상권 분류라고 해석하지 않는다.

## 검증

- 전국 산출물의 해시·분류 합계·고유 식별자·좌표 범위·선 형상을 검사한다.
- 100m 안팎과 끝점, multipart 사이 허구 연결 방지, 월/업종/시군구 필터, 중복 및 uint32 업소 ID를 테스트한다.
- 로컬 Spring API와 연결해 서울 명동길, 부산 광복로, 전북 익산 고봉로를 선택하고 OSM 기반 바탕 지도와 육안 대조했다. 별도 OSM 형상 다운로드는 서버 응답 제한/시간 초과로 실패했으므로 수치적인 최근접 도로 오차를 검증했다고 주장하지 않는다.
- 브라우저에서 면·길 동시 켜기, 지도 클릭, 도로명 검색, 분류 필터, 지역 전환, 기간 변경, 업소 상세 연결을 점검했다. 1440·820·375px 및 두 테마를 확인한다.
- frontend build, lint, Node 테스트를 실행한다. 기존 대형 번들 크기 경고는 남아 있다.
