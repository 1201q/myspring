# 행정동별 개폐업 증감

하단 `동별 개폐업 증감`을 켜면 현재 재생 지역의 행정동을 색칠한다. 읍·면도 같은 단위로 포함한다. 청록은 개업 우세, 회색은 폐업 우세이며 절대 증감이 클수록 진해진다. 개업과 폐업이 같은 동, 기간 내 기록이 없는 동은 별도 색상이다. 비율이 아니라 `선택 기간 개업 − 폐업` 건수다. 색상 강도는 현재 기간·업종의 최대 절대 증감을 기준으로 조정하므로 서로 다른 조회 조건의 진하기를 직접 비교하지 않는다.

동 영역에 마우스를 올리면 동 이름·기간·개업·폐업·증감 툴팁을 표시하고, 클릭·터치하면 하단에 선택 동의 건수를 유지한다. 사업장 점은 영역보다 위에서 기존 상세 조회를 유지한다. 업종과 기간 변경 시 선택 동의 건수도 다시 계산한다. 다른 지역으로 전환하면 기존 동 영역과 상세는 즉시 숨기고 새 지역을 준비한다. 토글을 끄거나 지역 전환 시 Worker를 종료하고 요청을 취소한다. 실패 시 재시도를 제공한다.

## 데이터와 성능

- 경계: SGIS를 가공한 vuski/admdongkor의 2026-10-01 **행정동** light 경계. 기존 시도 경계와 같은 commit으로 고정했다. 서울 427개를 포함한 전국 16개 재생 지역을 각각 파일로 분리했다. 원본 출처·라이선스·지역별 개수·SHA-256은 `frontend/public/data/dongs/source.json`에 있다.
- 배정: 주소의 법정동 명칭을 사용하지 않고, 기존 재생 파일의 WGS84 좌표를 실제 Polygon/MultiPolygon과 비교한다. 공간 격자로 후보를 좁히고 내부 구멍과 섬을 보존한다. 공유 경계는 행정동 코드 순으로 한 동에만 배정한다. 가까운 동으로 강제 배정하지 않는다.
- 현재 구조는 시도별 전체 이벤트를 이미 브라우저로 받으므로 별도 DB 배치/API 대신 Web Worker에서 사업장별 배정을 한 번 캐시하고 `행정동 × 업종 × 개폐업 × 월` 누적합 인덱스를 생성한다. 기간 변경은 누적합의 차이로 계산해 공간 연산을 반복하지 않는다. 이 인덱스는 현재 지역·활성화 세션 동안만 유지하며 새 데이터셋은 새 Worker로 처리한다.
- 단순화 경계와 재생 파일의 float32 좌표이므로 경계 부근에는 오차가 가능하다. 어느 동에도 속하지 않는 이벤트는 미배정으로 유지하고 `집계 기준 · 미배정 건수`에서 확인한다. 좌표가 없어 기존 재생 파일에 들어오지 않은 기록까지 포함한 총 미배정 수는 아니다.
- 과거 기록도 위 경계에 재집계한다. 과거 행정구역이나 과거 사업장 주소를 복원하지 않는다. 일반 빌드·사용자 브라우저는 원본 GitHub에 접속하지 않는다.

경계 재생성: `frontend`에서 `npm run build:dongs`. Node 24 이상에서는 프로젝트 루트에서 `node scripts/verify-dong-statistics.mjs seoul` 또는 `busan`으로 저장된 실제 재생 파일을 검증한다.

## 검증

`node --test src/*.test.mjs` 13개 통과, `npm run build`, `npm run lint` 통과. 기존 번들 크기 경고는 유지된다.

공간 테스트는 내부 구멍·섬·공유 경계·미배정 좌표를 확인한다. 기간·업종 테스트는 개폐업 별도 집계와 미배정 보존을 확인한다. 모든 16개 경계 파일의 SHA-256, 코드 유일성, WGS84 좌표와 폐합 링을 검사한다.

실제 서울 1,443,310 이벤트 / 427동, 부산 369,240 이벤트 / 206동으로 1·3·12개월·누적 × 전체·일반음식점·약국 총 24개 조건에서 `동별 합계 + 미배정 = 원본 이벤트 건수`를 확인했다. 서울 인덱스 생성 약 2초, 부산 약 0.35초이며 측정 환경에 따라 달라진다. 세부 결과는 `docs/data-samples/national/dong-statistics-*-verification.json`에 있다.

로컬 실제 API를 사용하는 브라우저에서 동별 색상, 12개월 전환, 종로1·2·3·4가동 클릭(전체 개업 290·폐업 191 → 약국 개업 3·폐업 2), 서울↔부산 전환과 필터 유지, 콘솔 오류 없음까지 확인했다.
