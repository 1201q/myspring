# 전국 인허가 지도: 추가 레이어 적용 가능성 조사

조사 기준일: **2026-11-14 (한국시간)**  
대상: 현재 저장소의 전국 인허가 개업·폐업 시간 재생 서비스  
범위: 앞서 제안한 10개 레이어와 지하철 확장, 상가·상권, 학교, 관광, 유동인구·매출·공실률 보완 후보

이 문서는 **공식 공개 안내·메타데이터·API 명세 조사와 현재 코드 검토에 따른 도입 판단**이다. 신규 원천의 전국 전체 파일 다운로드, 인증 API 실호출, 전국 건수·누락률 측정, 서비스 구현·배포는 수행하지 않았다. 따라서 ‘적용 가능’은 설계와 원천 제공 방식이 맞는다는 뜻이며, 수집·품질 검증까지 끝났다는 뜻은 아니다. 구현 전 통과 조건을 데이터별로 명시한다.

## 1. 우선 결정할 내용

현재 서비스에는 다음 순서가 적합하다. 순서는 공식 기관의 권고가 아니라 서비스 목적·전국 적용성·기존 코드 재사용성을 고려한 제안이다.

1. **개폐업 격자 밀집도와 선택 지점 반경 분석:** 기존 데이터를 활용하므로 외부 원천의 지역 편차가 추가되지 않는다.
2. **행정동 주민등록 인구·연령·세대:** 전국 월간 자료를 우선 검증한다. 월별 개폐업과 비교하기 좋다. 주민등록 세대와 인구총조사 가구는 별도 지표다.
3. **버스정류장·주차장:** 지하철이 없는 지역의 입지를 보완한다. 수집 범위를 표시하는 조건으로 도입한다.
4. **전통시장·공원·학교:** 전국의 생활·방문 거점을 보조 표시한다. 이 중 전통시장은 서비스 주제와 특히 잘 맞는다.
5. **SGIS 격자 인구·사업체·종사자, 용도지역:** 연간 통계와 공간 자료의 결합·배포 조건을 확인한 뒤 도입한다.

**전국 기본 레이어로 바로 채택하기 어려운 후보**는 세밀한 유동인구, 추정매출, 개별 점포 공실, 전국 동별 임대료다. 공개 지역 자료나 표본 통계를 전국의 모든 동·점포로 확대 해석해서는 안 된다. 유료 전국 데이터가 없다는 뜻은 아니며, 이번 조사에서 전국 동일 조건의 무료 상세 데이터와 공개 재배포 계약을 확보하지 못했다는 뜻이다.

저장소 안내상 지도 대상은 15개 인허가 업종이며 유효 위치는 3,782,478건이다. 이는 기존 발행·검증 기록의 수치이고 이번 조사에서 DB를 다시 집계한 수치는 아니다. [현재 프런트엔드 안내](../frontend/README.md)

현재 재생 지역 ID는 프로젝트 자체 분류다. 외부 자료의 행정기관코드·법정동코드·SGIS 코드·TAGO 도시코드를 이 ID에 직접 대입하지 않는다. 특히 프로젝트가 묶어서 제공하는 지역과 외부 통계의 공표 지역이 다를 수 있으므로 원천 코드와 서비스 지역의 대응표를 별도로 둔다. 저장소의 지역 명칭을 외부 기관이 동일하게 사용한다고 가정하지 않는다.

### 2.2 전국 적용의 판정 기준

- **전국 공통 도입 후보:** 한 원천·한 정의로 전국 비교를 설계할 수 있다. 실제 전체 수집과 지역 누락 검사는 여전히 필요하다.
- **전국 취합·조건부 후보:** 전국 명칭의 자료가 있으나 제공기관·연계지역·대상 시설의 범위를 함께 표시해야 한다.
- **보조 통계 후보:** 넓은 지역·표본·연간 통계만 가능하여 상세 지도와 분리한다.
- **전국 기본 도입 보류:** 전국 상세 공개 데이터의 제공·재배포 조건을 확보하지 못했거나 현재 데이터만으로 의미가 성립하지 않는다.

## 4. 기존 데이터로 만드는 레이어

### 4.1 개업·폐업 밀집도와 고정 격자

**판정: 바로 설계·구현 가능한 우선 후보.** 외부 데이터 없이 기존 이벤트를 월·업종·위치별로 묶는다. 다만 전국 전체 사업체가 아닌 현재 서비스의 지원 인허가·유효 위치 범위다.

- 표시: 개업 건수, 폐업 건수, 순증감 중 하나를 선택하고 격자에 색칠한다. 부드러운 히트맵은 탐색용으로, 숫자 비교는 고정 격자로 제공하는 편이 명확하다.
- 줌을 바꾸어도 비교가 필요하면 격자 원점·투영좌표계·크기를 고정하고 격자 ID를 저장한다. 경위도 차이를 그대로 미터로 취급하지 않는다.
- 월·업종별 집계를 Worker 또는 발행 과정에서 계산하고 같은 기간 조건을 적용한다. 격자가 지나치게 많으면 사전 집계·타일 제공으로 전환한다.
- 현재 동별 증감과 밀집도 면 색상을 겹치면 읽기 어렵다. 면 색칠은 한 번에 하나만 선택하도록 한다.
- 전국 비교에서는 같은 수치 구간을 유지한다. 지역마다 자동으로 최대값을 맞추는 표현은 지역 안 탐색 모드로 명시한다.

**통과 조건:** 격자 합계 + 위치 제외 건수가 원래 집계와 일치할 것, 지역 경계에서 중복 집계하지 않을 것, 누적 이벤트를 영업 중 점포 밀도로 표시하지 않을 것. 성능 기준은 실제 최대 지역 데이터로 측정한다.

### 4.2 선택 지점·역·시설의 반경 분석

**판정: 가능. 시설 레이어보다 독립적으로 먼저 만들 수 있다.** 사용자가 지도에서 선택한 점을 중심으로 300m·500m·1km 원을 그리고 해당 기간 개업·폐업을 집계한다.

- 원 표시와 통계 계산에 같은 거리 정의를 쓴다. 위도·경도에 일정 숫자를 더한 사각 범위로 반경을 대신하지 않는다.
- 초기에는 선택한 재생 지역에서 이미 받은 점만 Worker의 공간 인덱스로 찾을 수 있다.
- 단, 원이 지역 경계를 넘으면 이웃 지역 점이 없다. 이 경우 결과를 ‘선택 지역 안의 반경 집계’로 제한 표기하거나 서버 공간 조회로 원 전체를 집계한다. 전국 반경 분석으로 공개할 때는 후자를 권고한다.
- 서버 구현 시 미터 단위 거리 계산과 공간 인덱스 사용을 함께 검증한다. 화면에 그리는 원과 서버 판정의 경계 오차도 확인한다.
- 역별 500m 원이 겹치면 동일 인허가가 여러 역에 속할 수 있다. 여러 역을 합산할 때는 인허가/이벤트 ID로 중복을 제거한다.

**표시 이름:** ‘직선거리 500m’. 도로망·출입구·횡단보도·경사 분석 없이 ‘도보 10분’, ‘실제 역세권 접근시간’으로 표시하지 않는다. 역 중심 좌표와 출입구 좌표도 구분한다.

### 4.3 장기 영업 분포

**판정: 가능하나 현재 이벤트 누적만으로 제공할 수는 없다.**

권고 지표는 ‘기준일 현재 날짜상 영업 추정 중이며 인허가 후 5년/10년이 지난 허가 건수’다. 이는 실제 동일 점포·동일 사업자의 연속 영업 인증이 아니다.

- 인허가일·폐업일을 허가 ID로 결합하고 기준일의 추정 재고를 만든다. 현재 바이너리는 월 단위 사건이므로 정확한 일수에는 원천 날짜가 필요하다.
- 1990년 이전 인허가처럼 재생 시작 전의 허가가 누락되면 장기 영업 분포가 왜곡된다. 시작 재고를 별도로 확보한다.
- 폐업 상태인데 폐업일이 없는 건, 인허가일 누락·역전 날짜·휴업 이력 미상은 품질 상태를 분리한다.
- 관측 종료까지 폐업하지 않은 건은 영업기간이 아직 끝나지 않았다. 이들을 폐업 완료 건과 섞어 평균 수명·생존율로 계산하지 않는다.
- 현재 좌표로 과거 영업을 표시하는 근사, 업종별 인허가 중복, 사업자 변경·이전 문제를 함께 표시한다.

**통과 조건:** 재생 시작 전 재고, 결측 처리, 날짜 기반 추정 정의를 확인한다. 과거 폐업 완료 건의 평균 기간과 기준일의 장기 영업 추정 건수를 별도 지표로 만든다. 기존 [데이터 설계안](commercial-area-timeline-data-design.md)의 사건·재고 구분을 따른다.

## 5. 인구·수요 레이어

### 5.1 주민등록 인구·연령대

**판정: 전국 월별 비교용 최우선 외부 통계 후보.**

공식 확인: 행정안전부 [지역별(행정동) 성별 연령별 주민등록 인구수](https://www.data.go.kr/data/15097972/fileData.do)는 무료 CSV, 월간 갱신, 이용허락범위 제한 없음으로 안내한다. 행정기관코드·기준연월·지역명·성별·각 연령 인구가 있다. [월간 조회 화면](https://jumin.mois.go.kr/ageStatMonth.do)도 제공한다. [공식 안내](https://jumin.mois.go.kr/ageStatGraphAgeLayer.do)는 시스템 공표가 2008년부터라고 설명하지만, 모든 세부 항목·지역의 모든 월을 이번 조사에서 확보한 것은 아니다.

적용 제안:

- 기본은 행정동별 총인구·인구밀도·전년 동월 증감, 연령 비중이다. 청년 연령 범위는 제품에서 명시하고 원천의 연령 범위를 임의로 동일시하지 않는다.
- 외국인·체류인구·통근·방문 수요를 모두 포함하는 통계로 설명하지 않는다. 주민등록 인구의 포함 범위는 수집 시 원천 정의를 함께 보존한다.
- 인구밀도의 면적은 매칭한 경계 면적으로 계산하고 단위를 명시한다. 인구수 자체와 인구밀도 색상을 분리한다.
- `인구 1천 명당 인허가 건수`를 만들 경우 대상 월·지원 업종·분모를 표시한다. 전체 상점 공급량·경쟁 강도를 직접 나타내는 지표로 단정하지 않는다.
- 월별 인구를 사업장 점의 반경 인구로 변환하지 않는다. 행정동 통계를 원에 면적 비례 배분하면 별도의 추정 모델이다.

**통과 조건:** 전국 파일의 행정동별 누락·중복·상위 합계 행 검사, 과거 파일 확보 범위, 행정기관코드와 현재 경계 코드 대응, 분동·통합 시계열 처리. 코드 문자열 앞자리만 잘라 SGIS 코드로 연결하지 않는다. 같은 이름의 동도 이름만으로 조인하지 않는다.

### 5.2 세대·1인세대

**판정: 인구와 함께 도입할 수 있다. 다만 지표 이름을 분리해야 한다.**

공식 확인: [행정동별 세대원수별 세대수](https://jumin.mois.go.kr/etcStatHouseholds.do)는 월별 조회를 제공하고, [성별 연령별 주민등록 1인세대수](https://www.data.go.kr/data/15097973/fileData.do)는 다운로드 후보가 된다. 후자의 상세 파일·라이선스·전체 컬럼은 구현 전 추가 확인한다.

적용 제안: 1인세대 비중·세대 수 증감으로 배후 거주 구조를 보여준다. 주민등록상 1인세대는 인구총조사의 1인가구와 다른 개념이므로 동일 계열로 합치지 않는다. 인구 원천과 세대 원천의 월·지역·등록구분을 맞춘다.

**통과 조건:** 분모가 전체 세대인지 명시, 상위 합계와 하위 행의 중복 제거, 인구총조사 가구와 별도 `metric` 유지, 전국 월별 파일과 제공 조건 확보.

### 5.3 SGIS 격자 인구·가구

**판정: 전국을 같은 공간 단위로 비교하는 데 적합하지만 2차 도입.**

공식 [통계데이터센터 제공 목록](https://data.kostat.go.kr/sbchome/serviceData/svcOfrDataList.do?curMenuNo=OPT_01_02_00_0)은 격자 인구·가구·주택을 2000·2005·2010·2015~2024년, 사업체·종사자를 2000~2024년의 연간 자료로 안내한다. 100m·500m·1km 등 격자 경계와 코드집 제공도 안내한다. 이 목록이 각 항목·연도·해상도의 모든 조합을 무조건 제공한다는 뜻은 아니다.

공식 [SGIS 자료제공 안내](https://sgis.mods.go.kr/view/pss/dataProvdIntrcn)는 회원 로그인·신청·약관 동의 후 파일을 받는 절차, EPSG:5179, 통계비밀보호에 따른 일부 N/A 처리를 설명한다. 공개 웹 지도 제공, 원본 재배포, 가공 타일 배포 조건은 신청 약관까지 확인해야 한다. 통계데이터센터의 제공 경로와 SGIS 포털 다운로드 경로의 조건도 각각 확인한다.

적용 제안:

- 첫 도입은 500m 또는 1km 격자에서 시작하고 실제 제공 범위·파일 크기로 결정한다. 100m 전국 다년 파일을 브라우저에 일괄 전달하지 않는다.
- ‘2024년 인구’처럼 연도를 고정 표시한다. 2026년 11월 재생에 2024년 자료를 보여주면 연도 차이가 드러나야 한다.
- 연간 값을 월별 변화처럼 보간하지 않는다. 과거 재생 중 선택 연도 자료가 없으면 미제공으로 표시하거나 사용자가 선택한 비교 연도를 유지한다.
- N/A·미수집·실제 0을 분리한다. 원천별 비밀보호 기준이 다를 수 있으므로 특정 숫자를 모든 API·격자 항목에 일괄 적용하지 않는다.

**통과 조건:** 필요한 연도·격자 크기의 전국 파일과 경계 확보, 허용된 공개·가공 배포 방식 확인, CRS 변환·격자 ID 일치·비밀보호 코드·합계 정합성 검사. 현재 동 경계에 면적 비례로 나누는 가구·인구 추정은 초기 범위에서 제외한다.

### 5.4 사업체·종사자 밀도

**판정: 연간 배후 일자리 지표로 가능. 실제 직장 체류인구·유동인구와 구분한다.**

위 SGIS 소지역 목록의 사업체·종사자 격자와 [공식 데이터 API 정의](https://sgis.mods.go.kr/developer/html/openApi/api/data.html)의 사업체수·종업원수 항목을 후보로 한다. API에는 토큰이 필요하며, 문서의 예시 연도를 최신 제공연도로 해석하지 않는다. 파일 제공 범위와 API 조회 범위는 별도 확인한다.

적용 제안: ‘종사자 밀도’·‘사업체 밀도’를 별도 선택하고 인허가 증감과 비교한다. 종사자 수가 많은 격자를 곧바로 점심시간 방문객 수로 표현하지 않는다. LOCALDATA의 허가 건수와 통계상 사업체 수를 합하거나 차감해 누락 사업체를 추정하지 않는다.

**통과 조건:** 항목별 조사 정의·제외 대상·업종 분류·비밀보호·해당 연도 경계 확인, 공개 배포 조건 확보. 연간 변화와 월간 개폐업은 나란히 비교하되 직접 인과관계로 설명하지 않는다.

## 6. 교통·생활시설 레이어

### 6.1 버스정류장과 버스노선

**판정: 정류장부터 조건부 도입 권고. ‘전국 모든 정류장 완전 수록’은 보장할 수 없다.**

공식 [전국 버스정류장 위치정보](https://www.data.go.kr/data/15067528/fileData.do)는 무료·이용허락범위 제한 없음의 연간 CSV다. 정류장 ID·명칭·WGS84 위경도·정보수집일·도시코드 등을 제공한다. 대상은 BIS가 구축되고 TAGO와 연계된 지자체이며 연간 수집 이후 변동은 반영하지 않는다고 안내한다.

공식 [TAGO 버스정류소정보 API](https://www.data.go.kr/data/15098534/openapi.do)는 서비스 가능한 도시코드 목록, 정류소 검색, 500m 근접 검색, 정류소별 경유노선을 제공한다. 인증키가 필요하다. 메타데이터상 실시간 갱신이 과거 정류장 이력 제공을 뜻하지는 않는다.

적용 제안: 파일을 정기 수집해 서비스에서 지역별 점 레이어로 제공한다. ID는 도시/관리기관과의 조합으로 유일성을 검증한다. 같은 이름의 상·하행 정류장은 합치지 않는다. 반경 분석에는 여러 정류장 원의 중복을 제거한다.

**노선은 별도 과제:** 경유 정류장 순서가 있어도 도로를 따라가는 실제 노선 도형이 있다는 뜻은 아니다. 정류장을 직선으로 이은 선을 공식 운행 경로로 표시하지 않는다. 전국 버스 노선 전체를 상시 그리기보다 정류장 선택 시 경유 노선 목록부터 제공한다.

**통과 조건:** TAGO 도시 목록과 실제 파일 지역 대조, 미연계 시군구 표시, 0·누락·뒤바뀐 좌표 검사, 운영 API 승인·한도 확인. ‘제공 자료 없음’과 ‘정류장 없음’을 구분한다.

### 6.2 주차장

**판정: 전국 취합 시설 레이어로 적합. 실시간 주차 가능 면수는 제외.**

공식 [전국주차장정보표준데이터](https://www.data.go.kr/data/15012896/standard.do)는 지자체가 관리하는 공영·민영 주차장의 위치·운영시간·요금·주차구획수 등을 취합하며 거주자우선주차구역은 제외한다. 무료, 반기 갱신으로 안내한다. 통합 페이지의 이용허락은 구체 유형 대신 안내 링크로 보이므로, 개별 제공기관 자료의 조건을 확인·기록한다.

적용 제안: 공영부터 켜기, 주차면 수로 점 크기 표현, 선택 시 요금·운영시간·기준일 표시. 상세 확대에서만 표시하고 전국 축척에서는 군집/개수로 요약한다. 실제 빈자리·방문객 수·회전율로 설명하지 않는다.

**통과 조건:** 관리번호 중복·기관별 중복 개방·좌표·면수 결측 검사, 전국 기관별 제공·기준일 표 작성, 최신 요금으로 오해하지 않도록 기준일 노출. 표준 API의 전체 조회 가능 범위와 한도는 실제 수집 전 확인한다.

### 6.3 공원

**판정: 도시공원 거점 표시로 도입 가능. 전국 모든 녹지와 동일하지 않다.**

공식 [전국도시공원정보표준데이터](https://www.data.go.kr/data/15012890/standard.do)는 조성 완료된 도시공원이 대상이며 미완료 공원은 제외한다. 공원 종류·위경도·면적·시설·지정고시일 등을 안내하며 무료·연간 갱신이다. 구체 이용허락은 제공기관별 확인이 필요하다.

적용 제안: 우선 대표 위치와 공원명만 표시한다. 면적 숫자만으로 실제 공원 경계를 그리지 않는다. 지정고시일은 실제 개장일과 구분한다. 공원 주변 카페·음식점 개폐업은 탐색 비교이며 공원이 개업을 유발했다는 결론으로 제시하지 않는다.

**통과 조건:** 관리번호·좌표·기관 중복·실제 대상 범위 검사. 면 표시를 원하면 별도 경계 원천·라이선스·ID 연결을 추가 조사한다. 입구 접근성 분석도 대표점 반경과 분리한다.

### 6.4 전통시장

**판정: 전국 지역 상권의 거점으로 2차 후보 중 우선 추천.**

공식 [전국전통시장표준데이터](https://www.data.go.kr/data/15012894/standard.do)는 지자체가 전통시장으로 인정한 장소가 대상이다. 시장명·유형·개설주기·좌표·점포수·취급품목·개설연도 등을 제공하며 무료·연간 갱신이다. 구체 이용허락은 제공 자료별 확인이 필요하다.

적용 제안: 시장 위치와 장날, 주변 개폐업 반경 분석을 제공한다. 전국 모든 상점가·골목상권을 포함한다고 설명하지 않는다. 원천 점포수는 해당 시장의 제공 시점 수치이고, 서비스의 인허가 점 수와 단위가 다르다.

**통과 조건:** 시장 식별자 유무·중복·장날 형식·좌표 검사. 좌표 주변 원을 ‘시장 공식 경계’로 사용하지 않는다. 경계가 필요한 분석은 별도 원천을 확보한다.

### 6.5 학교

**판정: 초·중·고 주변 생활업종 탐색에 활용 가능.**

공식 [전국초중등학교위치표준데이터](https://www.data.go.kr/data/15021148/standard.do)는 학교 ID·급·설립일·본교/분교·운영상태·좌표 등을 안내하며 무료·수시 갱신이다. 이용허락은 구체 유형을 별도로 확인한다.

적용 제안: 운영 학교를 학교급별로 표시하고 반경 개폐업과 함께 본다. 대학·유치원·학원·학생 수는 이 자료만으로 제공하지 않는다. 설립일과 운영상태만으로 학교의 과거 이전·휴교·폐교 이력을 모두 복원하지 않는다.

**통과 조건:** 학교 ID·캠퍼스/분교·운영상태·좌표, 이전 여부 확인. 학생 수가 필요하면 별도 교육통계 원천과 학교 식별자를 검증한다.

## 7. 공간·상권 확장 레이어

### 7.1 용도지역·토지이용

**판정: 전국 공간자료를 활용할 수 있으나 지도 배포·질의 방식의 검증이 선행되어야 한다.**

공식 [토지이용계획정보(WMS/WFS/속성정보)](https://www.data.go.kr/data/15123973/openapi.do)는 공간범위 대한민국 전체, 무료, 이용허락범위 제한 없음으로 안내한다. 용도지역·용도지구 관련 원천 후보이며 실제 기능·레이어는 연결된 제공 서비스에서 확인해야 한다. [공간정보오픈플랫폼 WMS/WFS](https://www.data.go.kr/data/15058805/openapi.do)도 후보 경로다.

적용 제안:

- 첫 화면은 주거·상업·공업·녹지 등 분석 목적의 구분을 표시하되 원천 코드 대응표를 보존한다. 중첩되는 지구·구역을 하나의 지역 분류로 덮어쓰지 않는다.
- WMS는 지도 이미지 표시용으로 평가한다. 이미지의 색을 읽어 점포의 용도지역을 집계하지 않는다.
- 점포 포함·반경 분석에는 WFS나 허용된 벡터 파일이 필요하다. 필지별 속성 API를 전국 모든 점포마다 호출하는 방식은 초기 도입에서 피한다.
- 직접 호출·프록시·캐시·가공 벡터 타일 중 무엇을 허용하는지, 키·등록 도메인·호출량·좌표축 순서·줌 범위를 확인한다. 무료라는 이유로 무제한 복제·캐시를 가정하지 않는다.

**통과 조건:** 실제 레이어 식별자·전국 지역 응답·도형 CRS·중첩 규칙 확인, 제공자 이용 조건과 캐시/타일 재배포 가능 범위 확보, 과거 버전 유무 확인. 현재 용도지역을 과거 월의 지정 현황으로 표현하지 않는다. 인허가 가능 여부를 판단하는 법적 안내 기능으로 확장하지 않는다.

### 7.2 상가업소와 상권 경계

**판정: 전국 업종 분포를 보완할 수 있다. 기존 인허가와 별도 데이터 계열로 관리해야 한다.**

공식 [상가(상권)정보 파일](https://www.data.go.kr/data/15083033/fileData.do)은 영업 중인 전국 상가업소의 상호·주소·업종·좌표 등을 제공하며 무료·분기·이용허락범위 제한 없음이다. 파일에 없는 업소를 폐업으로 판정할 근거는 아니다.

공식 [상가(상권)정보 API](https://www.data.go.kr/data/15012005/openapi.do)는 전국 범위의 업소 조회와 별도의 상권 조회 기능을 안내한다. 현재 명세 기준 기본 경로는 `apis.data.go.kr/B553077/api/open/sdsc2`이며, 업종 체계는 대·중·소분류로 관리된다. 인증·실제 페이지 처리·운영 한도는 도입 시 확인한다.

적용 제안:

- 허가 대상이 아닌 소매·서비스업 등의 현재 분포를 별도 ‘상가업소’ 레이어로 제공할 수 있다.
- LOCALDATA 업종과 상권업종은 같은 코드 체계가 아니다. 업종 연결표의 버전·불명확 대응을 기록한다.
- 업소번호와 인허가 관리번호는 서로 다른 식별자다. 주소·상호만으로 합쳐 기존 이벤트 통계에 더하지 않는다.
- `storeListInRadius` 같은 업소 조회와 `storeZoneInRadius` 같은 상권 조회를 구분한다. 상권 조회가 전국 모든 지역의 연속적인 상권 경계를 보장하는지는 실호출로 확인한다.
- 전국 초기 적재는 분기 파일을 우선 평가하고, API는 변경·상세 보완 후보로 둔다. API의 수정일은 실제 개업일이 아니다.

**통과 조건:** 전국 파일 기준일·중복 업소·좌표 품질, 업종 매핑, 파일/API 일관성 검사. ‘인허가 건’과 ‘상가업소’의 수치를 구분하고, 현재 스냅샷을 과거 개폐업 재현에 사용하지 않는다.

### 7.3 관광지·문화시설·축제

**판정: 관광·숙박업 분석으로 넓힐 때 선택 도입 가능.**

공식 [한국관광공사 국문 관광정보 API](https://www.data.go.kr/data/15101578/openapi.do)는 전국 관광 콘텐츠, 위치 기반 검색, 행사 기간 검색, 수정일 조건 등을 안내한다. 무료 API이며 인증키가 필요하다. 이미지에는 공공누리 1·3유형이 섞여 있고 이용 제한도 별도로 명시되어 있다.

적용 제안: 사진 없이 관광지·문화시설 위치와 원문 링크부터 제공한다. 행사 시작·종료일은 기간 표시의 근거가 될 수 있지만 과거 행사 전체의 보존·조회 가능성은 별도로 확인한다. 수정일을 관광지 개장일로 취급하지 않는다. API 등록 콘텐츠는 전국 모든 방문시설의 전수조사도, 실제 방문객 수도 아니다.

**통과 조건:** 지역코드·분류 API의 현행 규격 확인, 콘텐츠 ID·좌표·행사 날짜·삭제 동기화·누락 지역 검사. 사진 도입 시 항목별 이용 유형을 보존하고 변형 허용 여부를 확인한다.

### 7.4 기존 지하철과 철도 확장

**판정: 기존 레이어는 유지하고, 장거리 철도·역·터미널 확장은 별도 범위로 검증한다.**

저장소 검증 기록 기준 수도권 24개와 비수도권 12개, 총 36개 선정 노선을 표시한다. OSM 스냅샷이며 과거 재생과 독립적이다. 환승역 표식 수를 고유 역사 수로 읽지 않는다. KTX·SRT·일반철도를 모두 포함한 전국 철도망이라는 뜻도 아니다. [수도권 출처·ODbL 안내](../frontend/public/data/subway/README.md), [비수도권 대조 기록](subway-regional-overlay-verification.md)

확장 시 철도·도시철도·버스 터미널을 별도 종류로 관리한다. 선로와 운행계통, 역 중심과 출입구를 구분한다. OSM 출처 표시와 가공 데이터 제공 의무 등은 기존 이용 조건을 이어받아 검토한다. 지하철 없는 지역을 위해서는 철도 노선 확대보다 버스정류장·반경 분석이 먼저다.

## 8. 전국 기본 기능으로 보류할 데이터

### 8.1 유동인구·생활인구

**판정: 세밀한 전국 공통 무료 레이어의 도입 근거는 아직 부족하다.**

공식 [서울시 상권분석 서비스 설명](https://golmok.seoul.go.kr/introduce.do)은 서울 공간 단위의 길단위 인구 등과 출처를 설명한다. 이를 서울 밖으로 확장하거나 주민등록 인구와 같은 정의로 합칠 수 없다. 정부의 [생활인구 관련 설명](https://www.korea.kr/news/policyNewsView.do?newsId=148936053)도 전국 통신 자료 구매와 지역 간 산정 차이 문제를 다룬다. 이는 특정 상품의 가격·계약·현재 전국 제공 범위를 확인한 자료는 아니다.

유료 구매를 평가한다면 전국/도서산간 포함 범위, 격자 크기, 시간 단위, 과거 기간, 표본 보정, 최소 인원 비공개, API/파일, 지도 공개·집계 재배포·보관·계약 종료 후 사용 조건을 함께 확인한다. 비용은 견적 전 미정이다. 제한된 연구실·안심구역 열람 자료를 공개 서비스 배포용으로 취급하지 않는다.

현재 대안은 주민등록 인구·종사자·교통시설을 각자의 이름으로 보여주는 것이다. 이들을 임의로 합쳐 ‘실제 유동인구’ 점수를 만들지 않는다.

### 8.2 추정매출

**판정: 전국 공통 기본 레이어 보류. 지역 한정 실험 또는 별도 계약 후보.**

서울 공식 안내는 카드결제와 보정비율에 기반한 추정매출을 설명한다. [현재 추정매출 데이터 안내](https://data.seoul.go.kr/bsp/wgs/dataView/data300View/1835.do)는 표준단위구역 전환과 2021년 이후 제공 범위를 별도로 공지한다. 일반 서비스 소개의 과거 기간 설명과 개별 데이터셋의 현행 범위가 다를 수 있으므로 세부 데이터 안내를 우선 확인한다.

도입 시 지역·업종·기간·공간 경계·카드 표본·매출 정의를 통일해야 한다. 상권의 매출을 개별 점포의 실제 매출로 표시하지 않는다. 인허가 업종과 카드/상권 업종 연결도 검증한다. 전국 무료 상세 API와 공개 배포 계약은 이번 조사에서 확보하지 못했다.

### 8.3 임대료·공실률

**판정: 공식 공표 지역의 분기 보조 패널에는 적합하지만 전국 동·개별 점포 면 색칠에는 부적합하다.**

한국부동산원 [통계산출 설명](https://www.reb.or.kr/reb/cm/cntnts/cntntsView.do?cntntsId=1051&mi=9802)은 공실 면적과 조사 면적에 기반한 공실률을 정의한다. [R-ONE](https://www.reb.or.kr/r-one/portal/stat/briefStatPage.do)은 표본 해석, 추가 지표, 오피스 지수의 기준·권역 개편을 안내한다. 현재 통계표의 지역·건물 유형·시계열 단절은 실제 파일에서 확인해야 한다.

적용 제안: 지역 선택 시 그 지역에 대응하는 공식 공표 단위의 임대료·공실률을 출처·분기와 함께 패널에 표시한다. 대응이 없으면 미제공이다. 원천이 제공하지 않는 경계를 임의로 만들어 상세 면 통계처럼 그리지 않는다.

**주의할 해석:** 인허가 폐업 신고 ≠ 빈 점포, 공실률 ≠ 폐업률, 임대료 ≠ 공시지가. 이 자료만으로 전국 공실 점포 위치를 만들 수 없다. 통계 파일/API의 이용·재배포 조건과 실제 다운로드는 후속 확인 대상이다.

## 9. 공통 데이터·화면 설계 제안

아래는 신규 제안이며 현재 구현된 API나 테이블을 뜻하지 않는다.

### 9.1 원천·시점·지역 제공 상태

각 레이어 발행본에 다음 메타데이터를 둔다.

| 필드 | 목적 |
| --- | --- |
| `layerId`, `datasetVersion`, `schemaVersion` | 레이어·발행본·형식 식별 |
| `sourceUrl`, `sourceDatasetId`, `provider` | 공식 출처 추적 |
| `sourceAsOf`, `downloadedAt`, `publishedAt` | 원천 기준일·수집일·우리 발행일 분리 |
| `timeMode`, `period`, `validFrom`, `validTo` | 스냅샷·월간·연간·실제 유효기간 구분. 모르면 NULL |
| `sourceRegionCode`, `codeSystem`, `boundaryVersion` | 서로 다른 지역 코드와 경계 구분 |
| `coverageStatus`, `coverageNote` | 제공·부분 제공·미수집·미지원·정의상 비대상 구분 |
| `license`, `attribution`, `distributionDecision` | 출처 표시·공개 가능 범위·검토 근거 |
| `rowCount`, `invalidCount`, `sha256` | 품질·무결성·재현 가능성 |

비밀보호 값은 관측값 수준의 `valueStatus=SUPPRESSED`, 수집 실패는 제공 상태 수준의 오류로 나눈다. 둘 다 0으로 바꾸지 않는다. 유효기간을 모르면 다음 수집일까지 해당 시설이 확실히 존재했다고 추정하지 않는다.

파일 저장은 원본 → 정규화 → 검증 완료 발행본으로 나눈다. 전국 취합 파일은 시군구별 건수·제공기관·기준일을 따로 관리한다. 원천 업데이트 실패 시 마지막 검증 완료본을 유지하고 기준일을 그대로 표시한다.

### 9.2 점·면·통계 저장과 조회

- **시설점:** `datasetVersion + provider + sourceFeatureId`, 종류, 좌표, 원천 지역, 기준일, 최소 속성. 전국 중복을 ID만으로 제거하기 전에 유일 범위를 검증한다.
- **면 경계:** 원천 면 ID·경계 버전·CRS·도형. 통계 테이블과 분리하고 동일 버전으로 결합한다.
- **월/연간 통계:** 원천 지역/격자 ID·통계 기간·지표·값·단위·결측 상태. 수집 날짜를 통계 기간으로 쓰지 않는다.
- **파생 개폐업 집계:** 기존 이벤트 발행 버전·업종·기간·공간 기준을 키에 포함한다. 원천 정정 시 재계산한다.

소량의 시설은 지역별 압축 GeoJSON으로 시작할 수 있다. 대량 격자·용도지역은 BBOX/벡터 타일을 검토한다. 신규 레이어의 다운로드 크기·압축률·최대 지역 건수는 아직 측정하지 않았으므로 구체 용량을 약속하지 않는다.

### 9.3 현재 화면에 적용하는 방법

1. `layers.ts`에 새 종류를 등록하고 `LayerSheet`를 교통·인구·주변시설·개폐업 분석으로 확장한다. 등록 메타데이터에는 사용 가능 지역·시점 유형을 포함한다.
2. 현재 `SubwayOverlay`처럼 시설을 독립 컴포넌트로 구성한다. 점포 선택과 시설 선택의 클릭 우선순위를 정한다.
3. 인구·용도지역·밀집도·동별 증감의 **면 색칠은 하나만 활성화**하고 지하철·시설점은 함께 볼 수 있게 한다.
4. 정보 패널에는 범례·통계 단위·원천 기준일·선택 기간·제공 범위를 표시한다. 통계 상세와 순위의 지역 범위를 일치시킨다.
5. 재생 월·시설 기준일·인구 연도가 다르면 각각 표시한다. 비교를 위해 최신 스냅샷을 고정할 수는 있지만 해당 과거 시설 현황이라고 설명하지 않는다.
6. 통계 원천의 시작 시점 이전에는 레이어가 미제공임을 표시한다. 미래 통계를 과거의 동시점 자료로 자동 대입하지 않는다. 당시 이용 가능 정보 분석이 필요하면 공표일도 제한한다.
7. 레이어를 켤 때만 로드하고 지역·버전별 캐시한다. 요청 취소·테마 변경·레이어 해제 시 리소스를 정리한다.

### 9.4 전국 서비스의 운영 비용

공공 원천이 무료여도 원본 보관·정규화·공간 집계·타일 저장·트래픽·키 갱신·출처 표시 유지 비용이 발생한다. 초기에는 정기 배치 수집과 버전 고정 파일 배포를 우선한다. 브라우저가 사용자 이동마다 외부 API를 직접 호출하면 전국 사용자 수에 따라 호출량과 장애가 증폭된다.

인증키는 수집/서버 측에 둔다. 단, 지도 제공자가 브라우저용 도메인 제한 키를 요구하는 경우에는 해당 계약 방식으로 별도 설계한다. 레이어별 장애가 인허가 재생까지 중단시키지 않도록 독립적인 오류·재시도를 제공한다.
