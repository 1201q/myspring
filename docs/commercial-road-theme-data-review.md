# 길단위 상권·주제별 SHP 활용 검토

확인일: 2026-11-22. 사용자 제공 전북 CSV와 공식 상품 안내·정의서, 공식 MZ SHP 원본을 검사했다. 이번 작업은 선정 판단이며 지도 레이어 추가 구현은 하지 않았다.

2026-11-23에는 사용자가 제공한 Desktop/data의 전국 CSV·SHP 네 묶음 전체를 추가 검사했다. 전국 대조 결과와 좌표계 정의는 아래 ‘전국 원본 대조’ 절을 따른다.

## 길단위 골목·발달 상권

- [골목상권 상품](https://www.bigdata-transportation.kr/frn/prdt/detail?prdtId=PRDTNUM_000000001010)
- [발달상권 상품](https://www.bigdata-transportation.kr/frn/prdt/detail?prdtId=PRDTNUM_000000001013)

브라우저에서 두 상품 모두 제공기관 오픈메이트, 2023년 1분기 자료, 무료, CSV/ZIP, 갱신주기 1년, 페이지 업데이트 2023-08-21로 표시되는 것을 확인했다. 주기가 1년이라는 안내만으로 2024년 이후 자료가 있다고 판단하지 않는다. 과거 자료는 메일 문의 안내가 있으나 실제 과거 버전은 확보하지 않았다.

길이 필드와 투영 좌표에서 계산한 선 길이가 수치 오차 범위에서 일치했다. 날짜·매출·유동인구·업소 수 컬럼은 없다. 공란을 골목상권으로 재분류하지 않으며, 발달 여부가 있는 4,377개 구간만 발달상권 강조 후보로 사용한다. 골목상권은 별도 원본의 분류값을 확인해야 한다.

상품의 정의서에는 형상이 WKT이며 KATEC 좌표계라는 안내가 있다. 실제 좌표는 경도·위도가 아니다. 골목상권 상품에는 KOTI-KATEC 투영이 어긋난다는 공개 문의가 있었으나 답변은 기관 전달 안내뿐이고 구체 투영식은 제시하지 않았다. KATEC라는 이름만으로 임의 EPSG를 지정하지 않는다. 원천 투영 파라미터 확인 및 서로 떨어진 지역의 실제 도로 표본 대조가 필요하다. 정의서의 분류 필드명 `TA_FLG`와 실제 CSV `SG_FLG` 차이도 기록한다.

상품에 무료라고 표시되지만 외부 웹지도 표시·가공 GeoJSON 배포 조건은 이번 확인에서 확정하지 못했다. 다른 포털의 CC0 표기를 원판매처 조건 대신 사용하지 않는다.

검사 범위:

- 34개 CSV의 컬럼 구조는 모두 같고 열 수·LINESTRING 접두 형식 오류는 없었다. 선의 자기교차나 도로 네트워크 연결성 전체를 검사한 것은 아니다.
- 각 CSV와 대응 DBF의 행 수·속성 순서를 대조했다. 문자열은 공백 제거, 길이는 부동소수점 오차 허용 후 모든 값이 일치했다.
- SHP는 모든 레코드가 PolyLine(type 3), 총 정점 10,177,586개다. 유한 좌표 여부와 레코드 수를 검사했고 CSV·DBF·SHP 행 수가 일치한다. CSV와 SHP의 모든 정점을 별도로 직접 대조하지는 않았다.
- `CTY_CD + RD_NM + ID` 조합은 시도별 파일 안에서 중복이 없었다. 운영 식별자는 자료 버전·시도까지 포함해 만들 수 있다. 다음 연도에도 같은 구간 ID가 유지된다는 보장은 없다.
- CSV는 UTF-8, SHP의 DBF는 CPG 안내에 따라 EUC-KR이다. 같은 디코더로 읽으면 SHP 한글이 깨진다.
- 원본에는 소진공 주요상권 번호가 없다. 현재 상권 영역과의 연결은 코드 조인이 아니라 좌표 변환 후 공간 중첩으로 확인해야 한다.

**좌표계 추가 확인:** 이번 SHP 34개에는 모두 동일한 `.prj`가 있다. 파라미터는 Bessel 1841(장반경 6,377,397.155m, 역편평률 299.1528128), Transverse Mercator, 중앙경선 128도, 원점위도 38도, 축척 0.9999, False Easting 400,000m, False Northing 600,000m이다. CSV만 봤을 때 미확인이던 투영식은 확인됐다.

다만 PRJ의 CRS 이름은 `unknown`, Datum은 `D_Unknown_based_on_Bessel_1841_ellipsoid`이며 WGS84로의 datum 변환 파라미터는 없다. 임의로 EPSG 코드를 붙이지 않는다. WGS84 변환 시 datum 처리와 실제 도로 위치의 오차를 표본 확인한 후 발행한다.

선정안: 바탕 도로 한 벌에 `골목/발달/미분류`를 결합한다. 상세 지도에는 분류된 112,838개 구간만 시도별·화면 범위별로 불러오는 방식이 적합하다. 미분류는 ‘상권 없음’이 아니라 원천에서 두 분류값이 공란인 상태다. 기존 1,227개 상권 폴리곤은 영역 집계용으로 유지하고 길 분류는 보조 표현으로 쓴다.

- 주요 필드: `MJR_BZZNNO`, `MJR_BIZON_`, `BIZON_ARE_`, `MRKT_SE_NM`, `MRKT_CD`, 최소/최대/중심 좌표, `ARA`, `SGG_CD`, `DONG_CD`, 생성·수정 정보.

- `.prj`가 포함되지 않았고 `.qmd`의 CRS도 공란이다. 도형 좌표는 투영좌표이므로 원천 CRS를 확인해야 한다. 기존 위경도 CSV와 다른 CRS를 가정 없이 합치지 않는다.

MZ 파일은 주제 선정 영역의 표시 후보로 활용할 수 있지만 공개 소개만으로 수치 지표를 만들 수 없다. 1,060개가 주제 선정된 전부인지·선정 기준은 무엇인지도 후속 확인 대상으로 둔다. 이 파일에서 전통시장·상점가 전국 경계를 확보한 것은 아니다.

## 서비스 적용 판단

1. 기존 주요상권 폴리곤을 기본 분석 범위로 유지한다.
2. 길단위 자료는 ‘2023년 1분기 발달/골목 상권 길’이라는 별도 선 레이어 후보로 선정한다. 분류값이 있는 구간만 표시하고, 상세 확대에서 도로명과 함께 보여준다.
3. MZ·회식·배달 등은 원본 검증 후 ‘주제별 상권’ 필터로 붙인다. 같은 상권에 여러 주제가 겹칠 수 있으며 배타적인 구역 분할로 취급하지 않는다. 기존 ID와 연결되면 기존 경계의 재사용 가능성을 먼저 검토한다.
4. 2023년 길 또는 2025년 주제 영역을 고정한 채 과거 개폐업을 비교하는 기능은 가능하다. 그 선택 월 당시의 길·MZ 상권이었다고 표현하지 않는다. 주제 선정 시점보다 과거 사건과의 관계는 사후 비교이며 미래 예측 성능의 증거가 아니다.
5. 길은 면적이 없으므로 점포를 선 내부 포함으로 집계할 수 없다. 도로 연결·최근접 구간 또는 거리 버퍼 등 별도 배정 규칙이 필요하며, 임의 거리로 만든 면을 원천 상권 경계로 부르지 않는다. 평행 도로·교차로의 중복 배정도 검증한다.

좌표계·이용 조건·선정 의미가 확인되면 길단위 레이어의 시범 지역 도입이 가능하다. 새 형상을 도입하기 전 길단위 골목상권과 주제 SHP 나머지 파일의 실물 검사가 우선이다.
