# 상권 데이터 선정과 표시 방식

작성일: 2026-11-22 (한국시간)

## 이번 브랜치 범위

`feature-commercial-area`에서는 상권 관련 데이터의 선정 기준과 화면 표현을 정한다. 사용자 요청에 따라 주요상권 경계의 원본 확보와 지도 레이어 구현까지 진행한다. 실제 확보·구현 범위는 [상권 경계 구현·검증](commercial-boundary-implementation.md)에 기록한다. 나머지 ‘우선 선정’은 제품 방향이며 도입 완료를 의미하지 않는다.

기존 [주변 환경 조사](nationwide-context-layer-research.md)의 인구·세대 도입 보류 결정을 유지한다. 횡단보도·육교·지하철 등 교통·보행 레이어는 해당 조사 문서를 따르고, 이 문서는 상권 자체와 상권을 설명하는 시설에 집중한다.

## 소상공인365에서 참고할 구조

공식 [기준 데이터 안내](https://bigdata.sbiz.or.kr/#/apiMain/commercialGuide/2)를 브라우저에서 확인했다. 소상공인365는 점포 현황, 인구와 소비, 교통, 주거·집객시설, 공간 경계를 결합한다. 우리 서비스도 개폐업 사건에 주변 맥락을 더하는 구성을 참고한다.

안내 페이지는 해당 서비스가 사용하는 원천과 갱신 현황을 설명한다. 외부 개발자에게 같은 자료를 모두 제공한다는 명세가 아니다. 특히 통신·카드·신용평가·배달 사업자 자료의 서비스 내 조회 가능 여부와 외부 재배포 가능 여부를 구분한다. 페이지 하단에는 상업 목적이 아닌 개인 용도 이용 안내가 있으므로 화면의 수치를 수집해 우리 서비스에 재배포하는 방식을 전제하지 않는다. 공공데이터포털에 별도로 개방된 자료는 그 자료의 제공 조건을 따로 확인한다.

| 참고 축 | 우리 서비스에서의 역할 | 선정 판단 |
| --- | --- | --- |
| 점포·업종 | 인허가 사건 외에 현재 상업 구성을 설명 | 우선 선정 |
| 주요 상권 영역 | 사용자가 이해하기 쉬운 이름과 분석 범위 제공 | 우선 선정 |
| 시장·학교·기타 집객시설 | 사람들이 방문하는 목적과 주변 업종의 관계 탐색 | 시장·초중고 우선, 나머지는 원천 조사 후 선정 |
| 공동주택 | 배후 주거 규모를 설명할 후보 | 후속 후보. 위치만으로 구매력을 추정하지 않음 |
| 주거·직장·유동인구 | 수요 기반과 시간대별 이용 맥락 | 이번 도입 범위에서 보류. 종사자 통계와 신평사 직장인구는 다른 지표 |
| 매출·소득·소비·배달 | 소비 규모와 업종 수요 비교 | 별도 제공 계약·공개 범위 확인 전 보류 |
| 기초구역·행정동 | 집계와 비교의 공간 기준 | 기존 경계 활용. 원천별 구역 체계를 동일시하지 않음 |

공식 안내에서 확인한 시점의 예: 점포·유동인구·매출·배달은 2026년 8월, 주요상권은 2024년 1월 기준으로 표시돼 있었다. 이 날짜는 소상공인365의 사용 자료 기준이며, 공개 파일·API의 기준일이나 과거 제공 시작일로 대입하지 않는다. 화면 상단의 소득소비 출처와 상세 표의 출처 표기가 다르므로 공급기관을 확정하려면 별도 확인이 필요하다.

| --- | --- | --- | --- | --- |
| [소진공 주요상권현황](https://www.data.go.kr/data/15090955/fileData.do), [상가(상권)정보 API](https://www.data.go.kr/data/15012005/openapi.do)의 상권 조회 | 행정동과 별도로 실제 주요 상업지역을 탐색하는 단위 | 실제 경계 좌표 검증 후 윤곽선과 명칭. 중심점만 확보되면 점으로 표시 | 상권명·원천 코드·영역 내 개폐업 사건 추이 | 전국 주요상권 대상이며 모든 상업지역을 덮지 않음. 좌표 형상·좌표계·도형 유효성 확인 필요 |

| [전국전통시장표준데이터](https://www.data.go.kr/data/15012894/standard.do) | 시장 중심 상권과 장날이라는 이용 맥락 제공 | 시장 위치점. 원본 경계가 없으면 임의의 시장 면을 만들지 않음 | 시장 유형·개설 주기·점포 수·취급 품목·주차장 여부 | 필드 누락과 기관별 기준일 확인. 시장 점포 수를 상가업소 수에 합산하지 않음 |
| [전국초중등학교위치표준데이터](https://www.data.go.kr/data/15021148/standard.do) | 학교 주변 생활업종의 변화를 탐색할 기준점 제공 | 학교급별 위치점 | 학교명·학교급·운영상태·주변 개폐업 | 대학·학생 수를 이 위치 자료에 포함된 것으로 간주하지 않음. 설립일로 과거 위치를 복원하지 않음 |

학교는 교육 목적 방문의 위치 단서다. 학생 수·학교급별 소비 수요·상권 매출을 위치만으로 추정하지 않는다. 병원·숙박시설처럼 기존 인허가에 포함된 시설은 같은 원천을 별도 관점으로 보여줄 수 있지만 새 점포처럼 중복 집계하지 않는다.

## 추가 후보의 배치

- 공동주택: 단지 위치·세대수 등을 실제로 확보할 수 있는 전국 원천을 조사한 뒤 후보를 확정한다. 소상공인365의 사용 항목이 다른 공개 자료에도 모두 있다는 가정은 하지 않는다.
- 공공·문화·유통시설: 하나의 ‘집객시설’ 완성 데이터가 있다고 가정하지 않고 시설 유형별로 원천과 범위를 확인한다. 초기에는 시설 위치와 종류만 제공하고 임의의 집객 점수는 부여하지 않는다.
- 임대료·공실률: [한국부동산원 공표 통계](https://www.reb.or.kr/reb/cm/cntnts/cntntsView.do?cntntsId=1185&mi=9803)를 후속 상세 패널 후보로 둔다. 조사 상권의 범위와 표본 통계의 성격을 유지하며 소진공 상권이나 작은 격자에 값을 복제하지 않는다.
- 관광 방문·소비: [한국관광 데이터랩](https://datalab.visitkorea.or.kr/datalab/portal/loc/getAreaVisitDataForm.do)을 지역별 추세 비교 후보로 둔다. 지표별 공간 단위·다운로드·이용 조건을 확인한 뒤 도입을 판단한다.
- 주차장: 기존 주변 환경 조사의 접근성 레이어를 재사용하는 방향이다. 상권 데이터 도입 때문에 별도 수집 체계를 중복 설계하지 않는다.

## 화면 표현 결정

### 전국·시도 수준

기존 개폐업 재생을 기본 화면으로 유지한다. 주요상권·가게·학교 마커를 전국에 동시에 표시하지 않는다. 행정구역별 개업 수·폐업 수와 그 차이를 보여주고, ‘활기 점수’로 단정하지 않는다.

현재 재생은 인허가/폐업 사건 집계다. 기초 영업 점포 재고가 검증되지 않은 상태에서는 개폐업률·생존율·영업 점포 순증감률을 제공하지 않는다. 인허가일을 실제 영업 개시일과 동일한 의미로 설명하지 않는다.

### 동네 수준

레이어 선택에 ‘상권 영역’, ‘현재 상가’, ‘전통시장’, ‘학교’를 제공한다. 초기 기본값은 모두 꺼짐으로 두고, 사용자가 ‘상권 영역’을 켜면 이름과 윤곽을 표시한다. 현재 상가는 충분히 확대한 상태에서 업종 필터로 선택해 표시한다.

상권 영역은 겹칠 수 있고 주요상권 밖에도 가게가 있으므로 행정동을 대체하는 전면 구획으로 쓰지 않는다. 미수록 지역은 ‘상권 없음’으로 표현하지 않는다.

상권·행정동·직선 반경은 각각 독립된 분석 범위다. 사용자가 범위를 선택하면 지도에서 그 범위만 강조하고 상세 패널의 집계도 같은 범위를 사용한다. 원천의 지역코드를 기존 서비스 ID에 직접 대입하지 않는다.

### 상세 패널

1. **선택 영역:** 이름·범위 종류·현재 선택한 사건 기간.
2. **개폐업 변화:** 기간별 개업 수·폐업 수·차이, 업종별 변화. 기존 인허가 15종 범위임을 표시.
3. **현재 업종 구성:** 소진공 현황 기준일과 업종별 점포 수·비중. 사건 집계와 별도 카드로 표시.
4. **주변 방문 거점:** 시장·학교 등 확보된 시설과 주요 속성.
5. **자료 정보:** 출처·실제 기준일·확인된 수록 범위. 누락과 0건 구분.

현재 상가와 과거 사건을 함께 켠 경우 ‘개폐업: 선택 기간 / 상가 현황: 별도 기준일’처럼 시점을 각각 표시한다. 현재 상가를 재생 월의 영업 점포로 표현하지 않는다. 상권 경계도 최신 버전으로 과거 사건을 묶었다면 그 사실을 표시한다.

점포 수·집중도는 현황 자료 내부에서 계산하고 인허가 자료와 단순 합산하지 않는다. 두 자료는 식별자·업종 체계·대상 범위가 다르므로 단순 차집합을 신규 개업·폐업으로 해석하지 않는다. 동일 시설로 보이는 점도 식별 관계가 검증되기 전에는 한 사업장의 확정 이력으로 합치지 않는다.

## 구현 착수 전 확인할 사항

이 브랜치의 결론은 **주요상권 영역·현재 업종 구성·전통시장·초중고 위치를 우선 검증 대상으로 선정하고, 지도 레이어와 영역 상세 패널로 표현한다**는 것이다.

후속 구현은 업소 현황 기준일 확인, 좌표·중복·지역별 누락 검사, 업종 분류 매핑과 이용 조건 확인이 끝난 자료부터 진행한다. 주요상권 경계는 전국 CSV 확보·좌표 보존 검사·지도 연결을 수행했으며 상세 범위는 [구현·검증 문서](commercial-boundary-implementation.md)를 따른다. 상가업소와 전통시장·학교 현황 수집 및 API 인증 호출은 수행하지 않았다.
