# 서울펄스 제공 기능 조사와 전국 서비스 적용 검토

조사일: **2026-11-14 (한국시간)**  
대상: [서울 개폐업 지도 / SEOUL PULSE](https://seoulpulse.vercel.app/#/)

## 1. 조사 범위와 결론

실제 지도에서 메뉴·업종 필터·데이터 정의를 확인하고, 연남동 리포트를 선택해 결과가 나오는 것을 확인했다. 외식 추정매출·지하철 승하차를 켜서 세부 옵션과 기준 시점 표시를 확인했으며, 기간 조회로 전환해 URL과 입력 조건이 바뀌는 것도 확인했다. 소개 페이지, 제작 노트, MCP 안내도 읽었다.

확인 수준은 다음과 같이 구분한다.

- **직접 확인:** 브라우저에서 기능을 열거나 결과·설명을 확인했다.
- **화면 안내:** 버튼·도움말·데이터 정의에서 제공한다고 설명한다. 모든 조건과 결과를 직접 시험한 것은 아니다.
- **제작자 문서:** 공개 소개·제작 노트·MCP 안내의 설명이다. 실제 서버 계산·원천 정합성을 독립 검증한 것은 아니다.

서울펄스는 **서울 행정동 단위의 개폐업 시간 탐색에 상권 지표·현재 상가·교통·생활인구를 결합한 서비스**다. 우리 서비스가 참고하기 좋은 점은 다음 세 가지다.

1. 개업·폐업 사건, 지속 영업 인허가, 현재 상가정보를 서로 다른 화면 조건으로 구분한다.
2. 단순히 레이어를 켜는 데서 끝내지 않고 동네 리포트·순위·추천 조건으로 이어진다.
3. 지표별 출처·시점·추정 여부를 표시한다. 다만 공개 설명 사이에 일부 불일치가 있어, 설명을 그대로 정답으로 채택하면 안 된다.

서울 전용 통계와 원천을 사용한 기능이 많으므로 **서울펄스에 기능이 있다는 사실은 전국 동일 데이터의 가용성을 입증하지 않는다.** 전국 원천 조사는 [추가 레이어 적용 가능성 조사](nationwide-layer-feasibility-research.md)와 함께 본다.

## 3. 기본 지도와 시간 탐색

### 3.1 개폐업·업종

지도는 개업을 점, 폐업을 X 형태로 표현한다. 업종 구분색과 개업/폐업 구분색 전환이 있으며 개업·폐업을 각각 켜고 끌 수 있다. 화면에서 확인한 업종 선택은 아래 19개다. 이는 원천 인허가 업종 19종과 같은 의미가 아니라 서비스가 재분류한 표시 그룹이다.

| 외식·판매 관련 그룹 | 생활·의료 등 그룹 |
| --- | --- |
| 카페·디저트, 한식, 분식, 주점, 치킨·호프 | 반려동물, 세탁소 |
| 일식·수산, 중식, 양식·세계요리, 패스트푸드 | 병원·의원, 약국, 체력단련장 |
| 기타 일반음식점, 기타 휴게음식점 | 비외식·특수 |
| 편의점, 즉석판매·가공 | |

전체 선택·기본·모두 해제 버튼이 있다. 기본 켜짐과 기본 꺼짐 업종을 구분한다. 원천 업태를 서비스 그룹으로 바꾸고, 상세에서는 원래 신고 내용을 함께 설명하는 구조다. 편의점은 상호 기반 보완 규칙도 있다고 안내한다.

**참고점:** 우리 서비스의 일반음식점·휴게음식점 등 원천 업종을 카페·디저트 같은 사용자용 그룹으로 다시 나눌 수 있다. 이 경우 원천 업종과 표시 그룹의 대응표·버전·예외를 보존해야 한다. 서울펄스의 업종 구분이나 숫자를 현재 15개 업종과 직접 비교해서는 안 된다.

### 3.2 재생·기간 조회

| 기능 | 확인한 동작·설명 |
| --- | --- |
| 시간축 | 지도 전체 안내는 1990~현재. 지표별 시작 시점은 다름 |
| 재생 단위 | 1개월·3개월·12개월·누적 |
| 이동·속도 | 재생/정지, 이전·다음 월, 배속 버튼, 시간 슬라이더 |
| 기간 조회 | 시작·종료 연월을 직접 입력. 진입 시 기존 조회 기간을 이어받음 |
| 합산/월별 | 전체 기간을 한 번에 보거나 해당 기간 안에서 월별로 탐색 |
| 빠른 기간 | 최근 12개월·3년·5년·전체, 연대별 기간 선택 |
| 공유 | 조회 기간이 URL 해시의 `from`, `to` 등으로 반영됨 |
| 자료 범위 표시 | 켠 지표의 시작 시점을 시간축에 별도로 안내 |

직접 확인한 예로 기간 조회 전환 후 `#/?from=2026.08&to=2026.10`이 표시되었다. 매출 레이어는 최신 개폐업 월보다 자료가 오래되면 마지막 제공 분기를 유지한다고 설명하고, 현재 매출 기준 분기를 패널에 표시한다.

우리 서비스에서도 기간·업종·지역·켜진 레이어를 공유 URL에 담는 구성을 참고할 수 있다. 최신 통계값을 유지해 과거·미래 재생과 함께 보여줄 경우에는 지표 기준일을 항상 드러내야 한다.

### 3.3 검색·개별 기록 탐색

검색창은 동·상호·주소 탐색을 제공한다. 데이터 정의에는 상호의 앞부분 검색, 법인·공백 표기 정규화, 주소 검색 후 주변 인허가 조회를 설명한다. 현위치 버튼도 있으나 이번 조사에서는 위치 권한을 요청하거나 사용자 위치를 전송하지 않았다.

같은 좌표에 쌓인 인허가는 확대 시 건수 표식과 목록으로 탐색하고, 해당 위치의 전체 이력으로 넓혀 보는 기능을 안내한다. 동일 좌표가 동일 점포·층·호를 보장하지 않는다는 설명이 붙는다. 개별 카드의 인허가 경과기간·원천 업태·같은 건물 직전 업소 연결은 공개 안내로 확인했으며, 이번 조사에서는 특정 가게 카드의 전체 연결 이력을 직접 검증하지 않았다.

**참고점:** 현재 지도에서 점이 겹쳐 기록을 선택하기 어려운 문제에는 좌표별 목록이 유용하다. ‘이전 가게’는 동일 건물/주소의 시간상 연결로 표현하고 동일 점포의 교체로 단정하지 않는다.

행사·팝업 표시는 업종을 대체하는 별도 분류가 아니다. 기존 카페 등 업종을 유지한 채 추정 플래그를 더하고, 집계에서 포함·제외하는 설계다. 우리 서비스에 도입할 때도 원본 사건 집계를 유지하고 분석용 필터를 분리하는 방식이 적합하다.

온라인 겸업 추정은 특히 주의가 필요하다. 화면 정의는 신고월과 음식점의 개폐업 시간 순서를 맞추지 않는다고 밝힌다. 따라서 일치하는 상호·위치가 있어도 해당 신고월에 실제 겸업했다고 해석할 수 없다. 자체 표본 정밀도를 전국 서비스의 정확도로 그대로 인용해서는 안 된다.

근거: [지도 레이어와 데이터 정의](https://seoulpulse.vercel.app/#/data). 실제 각 레이어의 전국 전량 정확도·추정 규칙 성능을 검증한 결과는 아니다.

매출 패널은 직접 켜서 전체 외식/카페·디저트와 세 가지 지표 선택을 확인했다. 모든 통계의 툴팁·필터 조합을 시험하지는 않았다. 특히 ‘개폐업 비율’의 모든 산식·분모 옵션은 미확인이다.

임대료 화면은 보증금을 월 금액으로 환산해 월세와 합산한 뒤 면적당 월 금액으로 설명한다. 실제 공실·매물 위치를 보여주는 기능과는 다르다. 상권변화 4유형도 좋음/나쁨의 점수보다 서로 다른 회전 특성의 구분으로 안내한다.

| 인구 히트맵 | 실시간 인구 자료의 밀도 표현 | 거점 대표 위치 주변 근사. 실제 정밀 격자 인구로 읽으면 안 됨 | 메뉴·정의 확인 |

교통의 월 합계와 시간대 프로파일은 같은 기준 기간이라고 가정하지 않는다. 역의 승하차 인원도 주변 동네 전체 유동인구와 다르다. 지도 배경의 철도선과 승하차 통계의 수록 노선 범위 역시 별개다.

## 6. 동네 리포트와 순위

### 6.1 실제 확인한 연남동 리포트

동 선택 입력에 ‘연남’을 넣고 마포구 연남동을 선택해 [해당 동 리포트](https://seoulpulse.vercel.app/#/report/%EB%A7%88%ED%8F%AC%EA%B5%AC%7C%EC%97%B0%EB%82%A8%EB%8F%99)가 열리는 것을 확인했다.

- 최근 12개월 개업·폐업 요약과 팝업 추정 소계
- 서울 전체 동 중 개업·폐업 순위
- 최신 월 잠정 집계 안내
- 상권변화 유형과 운영 기간의 서울 기준 비교
- 외식 추정매출·순위·건당 매출
- 현재 상가 수와 업종 구성 비중
- 업종별 1·3·5년 생존율의 연도별 차트와 서울 비교
- 월별 개업·폐업 추이, 업종별 최근 12개월 집계
- 연도별 개업·폐업 그래프를 펼치는 메뉴
- 리포트의 기간을 지도에서 재생하는 연결 버튼

조사 시 화면의 최근 12개월은 2025.11~2026.10이었다. 개별 숫자는 수집·정제에 따라 바뀔 수 있어 기능 설명의 기준값으로 고정하지 않는다. ‘동네 리포트는 최근 12개월’이라는 조건과 사용자가 지도에서 선택한 기간을 구분해야 한다.

서울 전체 리포트에는 상권변화 4유형의 동 수 분포와 업종별 개폐업 상위 동을 여는 메뉴도 있었다. 별도의 지도 업종 순위 패널과 직전 같은 길이 기간 대비 순위 이동 안내도 확인했다. 순위 이동은 건수 증감 자체와 다르며, 지도 업종 필터와 순위의 적용 범위가 같다고 가정해서는 안 된다.

**우리 서비스의 참고점:** 외부 데이터를 기다리지 않고도 동별 월 추이·업종 구성·순증·지역 내 순위·전년 비교를 현재 인허가로 먼저 만들 수 있다. 인구·교통은 추후 같은 리포트의 보조 영역으로 붙인다. 비교 기준은 서울 전체 대신 선택 시도/전국을 명확히 선택하게 한다.

## 7. 추천 탐색 조합

메뉴에서 다음 8개 프리셋을 확인했다. 각각 기간·업종·표시 모드·보조 지표를 묶어 탐색을 시작하게 한다. 이번 조사에서 8개를 모두 실행한 것은 아니다.

| 프리셋 | 결합하는 질문·조건 |
| --- | --- |
| 역세권 개업 | 역 이용량과 신규 인허가 분포 |
| 신생 가게 | 짧은 최근 기간의 개업 기록 |
| 오래된 가게 | 인허가가 오래 유지된 업종·위치 |
| 카페와 경사도 | 카페 폐업 위치, 지형, 실시간 인구 참고 |
| 카페와 주말 상권 | 카페 개업과 주말 매출 비중 |
| 생활 상권 | 생활업종과 직장인구 분포 |
| 음식업종의 온라인 겸업 | 통신판매 신고와 외식 이력 매칭 |
| 저임대 개업 | 낮거나 높은 환산임대료 지역의 신규 업종 |

프리셋의 분석 문구나 수치가 상관관계를 넘어 원인을 설명하는지는 별도 검증이 필요하다. 특히 최신 실시간 인구를 과거 폐업 위치에 겹친 모습은 당시 인구·매출 상황을 복원한 결과가 아니다.

**전국 적용 추천:** ‘최근 개업이 많은 동네’, ‘역 주변 변화’, ‘인구 감소와 개폐업’, ‘장기 인허가 분포’처럼 확보 가능한 원천 안에서 시작한다. 서울 지표가 필요한 프리셋을 전국 공통 메뉴에 그대로 넣지 않는다.

## 8. MCP로 제공하는 기능

공개 [MCP 안내](https://seoulpulse.vercel.app/mcp/)는 무료·무인증·읽기 전용 서버와 11개 도구를 소개한다. 이번 조사에서는 서버를 설치·등록하거나 도구를 호출하지 않았다. 아래는 문서상 제공 목록이다.

| 도구 | 제공한다고 설명한 내용 |
| --- | --- |
| `get_seoul_overview` | 데이터 범위·정제·분류·품질 개요 |
| `resolve_dong` | 동 이름의 후보와 정식 식별값 |
| `get_dong_openclose_series` | 동별 월/연 개폐업 |
| `rank_dongs` | 지표별 지역 순위 |
| `get_dong_category_recent` | 최근 업종별 개폐업 |
| `get_dong_transition_stats` | 직전 업소 연결·업종 전환 요약 |
| `get_dong_store_events` | 개별 사건 목록 |
| `query_nearby_stores` | 역 대표 좌표 주변 직선거리 조회 |
| `get_dong_indicators` | 보조 통계 |
| `get_dong_ecom_series` | 통신판매 신고 추이 |
| `get_transit_series` | 대중교통 이용 시계열 |

서버 주소는 `https://seoulpulse.vercel.app/api/mcp`로 안내되어 있다. 우리 서비스에서는 기존 집계·공간 API의 정의가 안정된 뒤 MCP를 고려할 수 있다. UI와 AI 도구가 동일 집계 로직을 쓰고, 응답에 지역·기간·원천 기준일·누락·주의사항을 붙이는 방향이 유용하다. 서울펄스의 서버를 연결해야 전국 기능을 구현할 수 있는 것은 아니다.

## 9. 공개 설명의 불일치·확인 필요 항목

다음은 조사 중 확인한 **설명 사이의 차이**이며 실제 데이터 오류를 확정한 것은 아니다. 일부 문서가 이전 발행본을 설명할 수 있다.

| 항목 | 관찰한 차이 | 조사 문서에서의 처리 |
| --- | --- | --- |
| 개폐업 규모 | 현재 데이터 정의는 인허가 149.6만 건으로 표시. MCP 안내는 다른 원장·정제 규모를 제시 | 사건/허가/정제본·버전의 정확한 대응이 불명확하여 하나의 확정 총량으로 합치지 않음 |
| 좌표 포함률 | 현재 화면은 93.4%, MCP 문서는 89.3%로 안내 | 발행본 차이 가능성. 각각 안내 수준으로 기록 |
| 지오코딩 | 같은 데이터 정의 안에 주소 보완 설명과 ‘지오코딩 추정 미사용’ 설명이 함께 존재 | 현재 실제 처리 경로는 코드·발행 메타데이터 없이는 확정하지 않음 |
| 생활인구 | 표에는 최근 7일 평균·짧은 지연으로 적혀 있으나 상세에는 원천 개편으로 최신 창이 2026.07에 머문다고 안내 | 일반 갱신 주기와 현재 실제 최신 자료를 구분 |
| 시간 범위 | 지도는 1990년부터, MCP 도구별 설명은 2000/2015년 이후 등으로 다름 | UI·도구·업종별 제공 범위를 분리 |
| 상가 업종 | 현재 상가 표시 그룹은 소진공 원천 분류와 다르게 재구성한 것으로 보임 | 표시 그룹 수를 전국 원천의 공식 분류 수로 인용하지 않음 |

데이터 기준·범위·버전 안내를 제공하는 점은 참고할 가치가 있다. 우리 서비스에서는 같은 메타데이터를 화면·문서·API에서 공유해 수동 설명의 불일치를 줄이는 편이 좋다.
