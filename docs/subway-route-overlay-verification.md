# 수도권 지하철 노선 확보·지도 검증

검증일: 2026-11-09. 실제 수집 데이터로 현재 프로젝트에 시험 레이어를 구현했다. 운영 서비스 배포는 수행하지 않았다.

## 확보 결과

| 항목 | 결과 |
| --- | --- |
| 원본 | OpenStreetMap Overpass, 기준 시각 2026-11-09 14:53:46 KST |
| 노선 범위 | 24개 도시·광역철도 노선 |
| 원본 운행 경로 | relation 232개; 상·하행, 급행, 단축 운행 포함 |
| 원본 선로 | 고유 way 3,100개; 타 노선과 공유하는 way 116개 |
| 출력 | 노선·way별 중복 제거 feature 3,216개, 역 표식 801개(환승역 노선별 중복) |
| 파일 크기 | 노선 1,313,081 bytes, 역 약 172KB, 압축 전 |
| 참조 무결성 | 사용 대상 선로·정차역의 참조 누락 0건, 잘못된 좌표 0건 |

독립적인 선로 조각을 이어 붙이지 않고 원본 geometry를 그대로 유지했다. 같은 선로를 공유하는 노선은 way별 표시 오프셋을 적용했다. 양방향이 서로 다른 실제 선로인 경우 두 선로를 유지하며, 공용 구간도 OSM에서 별개 way인 경우 정확히 같은 방식으로 분리되지 않을 수 있다.

원본 압축본·질의·해시·노선별 relation 목록은 [검증 자료](data-samples/subway/verification.json)에 저장했다. 기본 재생성은 오프라인으로 동작한다.

## 완전성 대조 결과와 한계

- 선정한 24개 노선 모두 경로와 색상값이 있다. 이는 선정 목록에 대한 존재 검사이며 최신 전체 수도권 노선의 완전성을 공인하는 결과가 아니다.
- 서울교통공사의 [공식 1~8호선 좌표 CSV](https://data.seoul.go.kr/dataList/OA-22534/L/1/datasetView.do) 276건 모두 같은 호선의 선로 500m 이내다. 최대 이격은 425m다. 인접 선로가 가까울 수 있으므로 이 검사만으로 해당 역의 정확한 위치를 보증하지 않는다.
- 정확한 역명 매칭은 273/276건. 당고개↔불암산, 뚝섬유원지↔자양, 총신대입구↔이수 차이가 남는다. 앞의 두 변경은 [서울시 자료](https://mediahub.seoul.go.kr/archives/2014269)로 확인했다. 원본 CSV는 보존했으며 통계를 맞추기 위해 이름을 덮어쓰지 않았다.
- 이름이 같은 역 표식과 공식 좌표를 별도 대조했을 때 신답 약 1,232m, 발산 약 1,020m 이격이 발견됐다. 어느 원본의 오차인지는 확정하지 않았으며 `flagged`에 보존했다. 공식 좌표를 무조건 지도에 적용하지 않았다.
- 연천·신창·광명·서동탄, 2호선 순환 구간과 양 지선 대표 역, 하남검단산·마천, 진접, 신내, 석남, 별내, 검단호수공원, 임진강·지평, 춘천·광운대 등 대표 종점·지선 역명 검사를 통과했다. 모든 역간 구간을 운영기관 원본과 일대일 대조한 것은 아니다.
- GTX-A 원본은 운정중앙~서울역과 수서~동탄의 분리된 선로다. 중간을 임의로 연결하지 않았다. 최신 직결 운행 여부의 공식 확인은 남아 있으므로 최신 운행 상태의 완전한 재현으로 해석하면 안 된다.
- 9호선과 수도권 광역철도·경전철 전체의 공식 역 목록 및 개통 이력 대조, 모든 노선의 공식 RGB 확인은 남아 있다. 역사적 노선 재현도 제공하지 않는다.

## 발견해 보정한 원본 문제

1. 우이신설선 OSM node `9459739637`은 삼양사거리 위치에 삼양 이름·번호를 중복 기재한다. [운영기관 역사정보](https://www.ui-line.com/filedown.php?fname=%2Fboard%2Fdata%2Finfo06%2F16140469138854.pdf&ori=%EC%9A%B0%EC%9D%B4%EC%8B%A0%EC%84%A4_%EC%97%AD%EC%82%AC%EC%A0%95%EB%B3%B4_20210223.pdf)의 삼양사거리 좌표에서 약 32m이므로 이름을 삼양사거리로 보정했다. 좌표는 원본을 유지했다.
2. 의정부 차량기지임시승강장 node `9221654398`은 원본 relation의 역할이 `inactive_stop`이다. [의정부시 2026-10-08 보도자료](https://www.ui4u.go.kr/portal/bbs/view.do?bIdx=368890&mId=0301020000&ptIdx=1709)에는 해당 승강장에서 시민들과 열차에 탑승한 내용이 있어 기존 좌표를 역 표시에 포함했다. 운행 시간표나 빈도를 추정하지 않는다.

보정은 [station-corrections.json](data-samples/subway/station-corrections.json)에 근거와 함께 저장한다. 원본 압축 파일은 수정하지 않는다.

모바일에서는 기존 순위 패널이 노선 버튼을 가려 패널 시작 위치를 조정했다. 소스 레이어는 가게 클릭 이벤트를 등록하거나 가로채지 않으며, 기존 사업장 점보다 아래에서 표시한다. 모든 사업장 상세 클릭의 회귀 검사를 수행한 것은 아니다.

브라우저 요청 취소(`net::ERR_ABORTED`)는 개발 모드 초기 효과 정리와 줌 전환 중 타일 취소에 기록되었다. 기능 오류·지하철 파일 실패는 발생하지 않았다. 빌드에는 기존 대형 번들 경고가 남아 있다.

## 사용

로컬 지도를 열면 왼쪽 위에 ‘지하철 노선’이 표시된다. ‘노선 선택’에서 특정 노선을 고를 수 있다. 줌 9부터 선, 12부터 역, 13부터 역명을 표시한다. 화면에는 ‘수도권 · 현재 노선 기준 · 시험 표시’를 명시한다.

재생성·검증 방법과 라이선스는 [데이터 안내](../frontend/public/data/subway/README.md)를 참고한다.
