# 레이어별 지역·기간 제공 현황

정리일: 2026-11-23. 전국 공통 원천을 우선하고, 부족한 범위는 지역별 원천을 조사해 검증된 지역에만 제공한다. 전국 자료가 없다는 이유만으로 지역 전용 레이어를 제외하지 않는다.

이번 문서는 저장소의 코드·발행 파일·기존 검증 기록을 검토한 결과다. 외부 원천의 최신 상태 재조사, 원본 재수집, 운영 배포 확인은 수행하지 않았다. 아래의 ‘발행’은 해당 브랜치에 서비스용 파일이 있다는 뜻이며 운영 반영 여부와 별개다.

## 검토 기준

| `feature-population` | `7e05022` | 인구·연령·세대 구현과 월·지역별 경계 대응 기록 |
| `feature-transport-layers` | `201feaf` | 버스정류장 구현·지역 파일, 교통·보행 시설 감사 기록 |
| `feature-overpasses` | `74117d9` | 신규 육교 레이어 구현은 없고 원천 조사 단계 |

이 현황의 최초 조사 시점에는 다른 브랜치를 병합하지 않았다. 이후 `feature-layer-integration`에서 인구·교통 브랜치를 병합했다. [통합 기록](feature-layer-integration.md)을 참고한다. 아래 표는 원래 검토한 브랜치·커밋 기준이며, 다른 브랜치의 경로는 `브랜치:경로`로 기재한다.

## 지역별 확인 수치

주요상권과 상권 길의 전남광주는 원천 광주·전남 건수의 합이다. 서비스 지역 ID는 프로젝트 분류이며 외부 행정구역의 유효성·개편 이력을 이 표로 판단하지 않는다. 강원 원천 코드는 상권 경계 `51`, 상권 길 `42`, 전북은 각각 `52`, `45`다. 코드의 체계·기준 버전을 보존하고 명시적으로 매핑한다.

### 기간·지표에 따른 예외

- 전남광주 인구: 2025-10~2026-06은 현재 경계 대응 **0/393**, 2026-07~10은 **393/393**이다. 과거 해당 지역 인구가 0명이라는 뜻이 아니다. 현재 매핑에서 표시 불가한 기간이며, 다른 원천 또는 과거 코드 대응은 추가 검증해야 한다.
- 경기 인구: 2026-10은 고덕동 `4122066000` 결측으로 **601/602**다. 대응률은 인구 포함률이 아니다.
- 인구 전월 증감: 첫 제공 월 2025-10은 비교할 이전 월이 없어 결측이다. 인구 수가 제공된다는 이유로 증감도 제공한다고 판정하지 않는다.
- 트렌드: 특정 지역·주제의 수록 결과가 비어도 그 지역에 해당 특성이 없다고 해석하지 않는다.
- 지하철: 광주 노선을 제공한다고 해서 전남광주 전체를 수록했다고 표시하지 않는다. 철도 권역과 서비스 지역의 교차 범위를 관리한다.

## 다음 적용 순서

1. [공통 메타데이터 규격](layer-coverage-contract.md)에 따라 기존 manifest·감사 기록을 연결한다. 원본 포맷을 한 번에 바꾸기보다 어댑터로 연결한다.
2. 상권·지하철부터 지역·기간·하위 유형별 제공 상태를 계산하고 레이어 선택 화면과 정보 패널에 표시한다.
3. 인구·버스 브랜치를 연결할 때 동일 판정에 통합한다. 각 브랜치의 렌더러와 수집기는 유지할 수 있다.
4. 미확인 범위의 전국 원천을 먼저 확인하고, 부족한 지역은 개별 원천을 조사한다. 정의·시간·도형·이용 조건이 다르면 별도 데이터셋으로 등록한다.
5. 실제 확보·검증·발행된 지역만 활성화한다. 기존 자료의 전수성을 확인하기 전에는 ‘전국 완전 제공’ 배지를 부여하지 않는다.

이 순서는 후속 구현 계획이다. 이번 변경은 현황과 규격 문서화까지이며 화면 동작은 바꾸지 않는다.
