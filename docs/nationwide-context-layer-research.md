# 전국 지도 신규 데이터 조사: 보행·교통·생활 거점과 과거 제공 범위

조사일: **2026-11-15 (한국시간)**  
대상: 현재 전국 인허가 개폐업 시간 지도  
사용자 결정: **인구·세대 도입은 미룬다. 구현에 앞서 신규 데이터의 전국 범위·과거 시점·서비스 적용 방법을 조사한다.**

지하철 시간 이력 후속 조사: 현재 36개 노선의 구간 개통일·폐지·이설 기록과 KTDB 과거 선형 후보의 존재는 [지하철 시간 이력 원천 조사](subway-temporal-history-source-research.md)에 별도로 정리했다.

## 1. 조사 결과와 확인 수준

전국 명칭의 시설 자료는 다수 존재한다. 그러나 시설 현황 파일의 갱신 주기만으로 과거 재생 가능 연도를 정할 수는 없다. 신규 데이터는 먼저 다음 세 방식으로 나눠 도입하는 것이 적합하다.

1. **기준일 고정 주변 환경:** 횡단보도·육교·버스정류장·주차장·시장·학교·공원·현재 상가. 선택한 시설 자료의 기준일을 개폐업 재생 월과 별도로 표시한다.
2. **통계 기간에 맞춰 비교:** 철도 이용량 등 실제 과거 기간이 확인되는 통계. 원천의 월간/연간 단위를 유지한다.
3. **배경 공간:** 지형·경사도·용도지역. 지형의 관측 시점, 용도지역의 버전이 과거 개폐업 시점과 다를 수 있음을 표시한다.

**핵심 신규 확인:** 전국횡단보도표준데이터가 존재한다. 다만 표준 위치·속성, 지자체 SHP, 생활안전지도 WMS는 서로 다른 자료이며 수록 범위·표현·이용 조건도 다르다. 서울펄스의 횡단보도 다각형을 전국 표준 CSV만으로 그대로 재현할 수 있다고 판단하지 않는다.

이번에는 공식 데이터 상세 페이지·명세·기관 문서를 열어 확인했다. 인증 API 실호출, 전국 원본 다운로드, 실제 좌표·누락률·과거 파일의 연속성 검증은 수행하지 않았다. 표의 날짜는 **공식 설명/파일명에서 확인한 자료 시점**이며, 바이너리·CSV 내용까지 검사한 확정 서비스 범위가 아니다. 공개 페이지에 최소 연도가 없는 항목은 미확인으로 남겼다. 이는 과거 자료가 존재하지 않는다는 뜻이 아니다.

## 2. 현재 서비스에 맞는 조사 기준

- 현재 재생은 선택 시도의 인허가/폐업 사건이며, 현재 영업 점포 재고가 아니다. 시설점·상가 현황을 사건 집계에 합산하지 않는다.
- 현재 `layers.ts`는 `dong`, `subway`, `rank`를 관리한다. 신규 시설은 독립 오버레이로 구성하고 공통 상세·반경 분석으로 연결할 수 있다.
- 현재 읍면동 증감은 현재 경계에 과거 사건을 배정한다. 외부 지역코드나 원천의 과거 행정구역을 서비스 자체 지역 ID에 직접 대입하지 않는다.
- **전국 취합 자료 있음**과 **전국 모든 시설이 완전하게 있음**을 구분한다. 시군구별 제공기관·기준일·좌표 유효 건수를 측정하기 전에는 완전성을 보장하지 않는다.
- 등록일·수정일·수집일·설치일·통계 기간을 각각 보존한다. 포털 등록일을 과거 제공 시작일로 쓰지 않는다.

현재 구성 근거: [프런트엔드 안내](../frontend/README.md), [전국 재생](national-playback-implementation.md), [읍면동 통계](dong-statistics.md), [레이어 정의](../frontend/src/ui/layers.ts).

## 4. 특히 새로 확인한 내용

### 4.1 횡단보도는 세 경로를 따로 평가해야 한다

**전국 표준 [S1]:** 위경도·종류·차로 수·폭·연장·신호등·턱낮춤·점자블록 등 속성을 제공한다. CSV/XML/JSON 등의 반기 갱신 자료다. 속성의 존재는 전국 모든 행에 값이 채워져 있다는 뜻이 아니다. 도형 방향·꼭짓점 없이 폭과 연장만으로 회전 사각형을 만들어 실제 횡단보도 면이라고 표시하지 않는다. 이용허락 링크가 구체 유형을 명시하지 않으므로 발행 자료별 조건을 기록한다.

**지자체 공간 자료 [S3~S5]:** 부산 자료는 2025-04-23의 신호등 설치 횡단보도만 대상으로 명시한다. 대구는 SHP·EPSG:5187 제공을 안내한다. 전북은 2020년 로드뷰 기반 2021년 구축 설명이 있으며 파일 형식 안내에 CSV/SHP 차이가 있고 공공누리 2유형이다. 지역별로 대상·좌표계·조건이 다르므로 하나의 전수 원천처럼 합치지 않는다. 실제 도형이 점/선/면 중 무엇인지도 파일을 열어 확인해야 한다.

**생활안전지도 [S2]:** 연속수치지도 횡단보도를 XML/WMS로 안내한다. 수집일 2024년·연간 갱신이며 공개 명세에는 과거 시점 선택 인자가 없다. XML 문서의 출력은 시설/지역 코드 중심이고 도형 좌표 필드는 보이지 않는다. WMS 표시는 공간 분석용 원본 벡터 확보와 다르다. 해당 페이지는 공공누리 4유형 및 신청 조건을 표시하므로 상업 서비스·가공 타일 배포를 바로 허용된 것으로 판단하지 않는다. 이 조건을 국토지리정보원 원본 전체에 동일하게 적용하지도 않는다.

**서비스 제안:** 먼저 표준 위치점과 선택한 지자체 SHP를 비교하는 검증용 화면을 만든다. 화면에는 ‘시설 기준일 고정’을 표시한다. 기본 켜짐으로 전국에 뿌리기보다 상세 확대에서 사용자가 켜는 보행 환경 레이어가 적합하다. 누락 지역에서는 ‘시설 없음’ 대신 ‘자료 미확보/부분 제공’을 표시한다.

### 4.2 보행자전용도로와 실제 도보권은 다른 작업이다

표준 [S9]는 시작·종료 좌표와 운영시간·지정일 등을 제공한다. 두 점을 직선으로 이은 선은 실제 곡선 도로의 형태를 보장하지 않는다. 보행자전용도로는 일반 보도·골목·계단·횡단보도 전체를 포함하는 보행 네트워크가 아니다.

육교·횡단보도·지하보도 점이 모여도 자동으로 도보 길찾기 그래프가 만들어지지 않는다. 출입구·계단·고가/지하의 높이 관계·연결 노드·통행 조건을 검증해야 한다. 초기 제품은 직선거리 반경 분석으로 연결하고 도보 5분/10분 표시는 도로망 검증 이후에 도입한다.

OSM은 기존 지하철 처리 경험을 재사용할 수 있는 보완 후보다. 공식 full-history 안내 [S22]에는 2007년 10월 API 전환 이후 객체 버전 이력이 설명돼 있다. **OSM 편집 시점은 실제 횡단보도 설치 시점이 아니다.** 한국 지역별 수록률을 검증하지 않은 상태에서 과거 전국 시설 복원의 근거로 쓰지 않는다. ODbL·출처 표시 조건은 원본·가공 DB 배포 방식에 맞춰 검토한다.

### 4.3 철도 이용량은 과거 비교 후보지만 운영사 범위를 분리한다

KTX 자료 [S12]는 2010~2023년을 설명하고, 컬럼에는 운행년월이 있다. 설명의 ‘연도별’ 표현과 실제 시간 컬럼이 다르므로 원본에서 월 중복·누락·총계 행을 확인한 뒤 월간/연간 여부를 확정한다. 연도별 수송실적의 2010년 역별 목록도 확인했으나 모든 연도의 모든 역·열차종별을 내려받아 검사한 것은 아니다.

전국에서 이용할 수 있는 **한국철도공사 해당 수록 역 통계**로 시작할 수 있다. KTX·일반열차·광역전철·도시철도·SRT의 서로 다른 통계를 합쳐 전체 역 이용량이라고 표시하지 않는다. 역명 변경·동명이역·이전 역사의 위치를 별도 매핑한다. 원 크기는 이용량, 선택 패널은 같은 기간 개폐업과 이용량 추이를 보여주는 구조가 적합하다.

STCIS [S13]는 별도 검증 가치가 높다. 공식 매뉴얼은 교통카드 분석과 OpenAPI 신청을 안내하지만, 이 조사에서 API의 정류장별 장기 시계열 제공 계약을 확정하지 않았다. 데이터안심구역 원자료나 합성 교통카드 자료를 전국 실제 승하차 공개 통계의 대체물로 간주하지 않는다.

### 4.4 설립·준공·개설일을 가진 현황도 과거 전수 명부가 아니다

현재 시장 목록에서 개설연도 이전을 숨기는 것은 가능해도, 이미 사라져 현재 목록에 없는 시장은 복원할 수 없다. 학교 이전·육교 철거·주차면 변경도 마찬가지다. 따라서 날짜가 있어도 아래와 같이 제한한다.

- 육교 준공일: 해당 현황의 준공 속성으로 표시. 그날부터 현재 위치·시설 상태가 같았다고 추정하지 않는다.
- 학교 설립일: 기관의 설립 속성. 현재 캠퍼스의 위치 유효 시작일과 구분한다.
- 시장 개설연도: 연도 정확도 속성. 임의로 1월 1일 개장으로 저장하지 않는다.
- 공원 지정고시일: 행정적 지정 속성. 실제 개장일로 사용하지 않는다.
- 상가 파일 수정일: 배포/정제 시점. 업소 개업일이 아니다. 파일 간 사라짐도 폐업 확정이 아니다.

### 4.5 지형은 시점을 고정한 배경으로 평가한다

SRTM [S19]은 2000년 2월 관측의 약 30m 자료이고, 버전 3에는 다른 원천의 결측 보완이 있다. 이를 ‘2000년 이후 매년 제공되는 지형’으로 설명하지 않는다. 골목 경사·계단·고가·상가 진입로를 정확히 나타내는 자료도 아니다. 한국 해안·산지·도시 표본의 결측·표고를 검사하고 필요한 수준에 맞는지 판단한다.

국토지리정보원 수치지도 [S8]는 무료·공공누리 1유형 경로이며 로그인·전용 다운로드 도구 안내가 있다. 지도 정보 이력 CSV에는 촬영·조사·제작연도와 고시일이 있지만, 이는 과거 각 연도의 전국 벡터가 모두 즉시 다운로드 가능하다는 보장이 아니다. 횡단보도 도형이나 지형을 추출하려면 실제 도엽·분류 코드·원본 버전을 확보해야 한다.

## 5. 화면과 데이터 발행 제안

### 5.1 시간 동작부터 정한다

| 자료 유형 | 재생 월을 바꿀 때 | 화면 문구 예시 |
| --- | --- | --- |
| 기준일 고정 시설 | 시설 자료는 유지, 개폐업 사건만 변경 | `개폐업 2019.01~12 · 시설은 선택한 기준일 현황` |
| 과거 스냅샷 확보 | 사용자가 선택한 발행본 기준으로 유지하거나, 검증된 대응 규칙으로 전환 | `상가 현황 2023년 3분기 · 개폐업 2023.01~12` |
| 월간/연간 통계 | 같은 기간 자료 조회. 없으면 미제공. 연간 값을 월간 변동으로 보간하지 않음 | `역 이용량 2020년 · 개폐업 2020.01~12` |
| 실제 유효기간 확인 시설 | 유효기간과 선택 월이 겹치는 검증 건만 표시 | `운영기간 확인 자료만 표시` |
| 지형·최신 용도지역 | 버전 고정, 과거 당시 환경이라는 설명은 하지 않음 | `지형 주 관측 2000년 · 용도지역은 선택한 발행본` |

시설 기준일보다 과거를 조회할 때도 맥락 비교는 가능하다. 다만 ‘당시 시설’ 모드로 자동 해석되면 안 된다. 과거 자료가 없는 레이어에는 시계열 연동 기능을 제공하지 않는다. 시설이 없는 것과 아직 확보하지 않은 것은 다른 상태다.

### 5.2 시설 선택을 공통 분석으로 연결한다

1. **보행 환경:** 횡단보도·육교·지하보도·보행자전용도로. 확대 시 표시하고 출처/기준일/제공 상태를 함께 노출한다.
2. **교통:** 기존 지하철·버스정류장·주차장. 역·정류장·주차장을 선택하면 같은 반경 분석 패널을 연다.
3. **생활·방문 거점:** 전통시장·학교·공원·관광시설·축제. 시설마다 서로 다른 리포트 대신 주변 업종과 개폐업 추이를 공통으로 보여준다.
4. **상가 현황:** 인허가 사건과 별도 범례·집계로 제공한다. 분기 스냅샷의 업종 구성은 선택 기간 개폐업과 구분한다.
5. **공간 배경:** 지형·용도지역. 읍면동 증감 등 면 색칠과 충돌하지 않도록 색칠 선택을 제한하고 점 시설은 함께 볼 수 있게 한다.

반경 패널의 초기 지표는 개업·폐업·순증감·전년 동기 건수 차이·업종 구성이다. 시설 주위 원은 직선거리이며 공식 상권 경계가 아니다. 원이 선택 시도를 넘으면 이웃 시도 미적재 문제를 해결하거나 ‘선택 지역 안 집계’로 한정 표시한다. 보행 환경 점수·실제 유동인구·창업 성공 점수는 이 원천만으로 만들지 않는다.

### 5.3 원본 검증을 위한 공통 산출물

각 원천마다 다음 파일/보고서를 확보한 뒤 구현을 확정한다.

- `source-manifest`: 원천 URL·기관·라이선스·기준일·수집일·파일명·해시·형식·좌표계. API 키는 수록하지 않는다.
- `coverage-report`: 원천 지역코드 기준 시군구별 제공기관·기준일 범위·행 수·좌표 유효 수·중복·미제공 지역. 없는 행을 시설 수 0으로 만들지 않는다.
- `history-inventory`: 실제 확보 가능한 발행본별 기준일·다운로드 경로·해시·공간 범위·누락 기간·스키마/분류 변경. 최초 한 파일의 존재와 전국 연속 시계열을 별도 판정한다.
- `geometry-report`: 점/선/면 구분·좌표변환·대표점/출입구 의미·도형 유효성·기관 간 중복 대응. 폭/연장 숫자를 실제 도형으로 대체하지 않는다.
- `distribution-decision`: 웹 지도 표시·가공·캐시·원본 재배포·상업적 이용의 허용 범위를 원천별로 기록한다.

검증용 표본은 수도권·비수도권 광역도시·농촌·제주/도서 지역을 포함한다. 지자체 취합 파일은 실제 기관별 제공 목록과 대조하며 표본 성공만으로 전국 완전성을 주장하지 않는다. 지도는 레이어를 켰을 때 지역/타일 단위로 로드하고, 원천 장애가 기존 개폐업 재생을 막지 않도록 한다.
