# 지도에서 재생 지역 선택

지도 시도 영역 또는 경계선 클릭과 하단 지역 선택은 같은 전환 로직을 사용한다. 선택 즉시 기존 상세·이벤트 점을 비우고 이전 다운로드를 취소한다. 월·기간·업종·속도는 유지하고 자동 재생은 멈춘다. 이미 선택한 지역을 누르면 재조회하지 않는다.

현재 재생 중인 지역은 지도 선택용 폴리곤에서 제외한다. 현재 지역에는 호버 배경·경계·지역 선택 툴팁·포인터를 표시하지 않으며, 다른 지역에만 선택 효과를 적용한다. 현재 지역의 사업장 점 상세 조회는 유지한다.

현재 지역은 하단 `지역명 선택됨`과 지역 선택 목록으로 표시하며 지도 위에는 별도 선택 색상을 적용하지 않는다. 평소 시도·시군구 경계는 숨기고, 마우스를 올린 지역에만 파란색 배경·경계선과 지역명·클릭 안내를 표시한다. 사업장 점은 영역보다 위에서 클릭을 받으므로 기존 상세 조회가 유지된다. 드래그는 지도 이동만 수행한다. 키보드용 하단 지역 선택도 유지한다.

경계는 [SGIS 자료를 가공한 vuski/admdongkor](https://github.com/vuski/admdongkor)의 2026-10-01 시도 light 경계다. 전남광주 통합을 포함한 재생 지역 16개에 연결했다. 표시와 클릭 모두 같은 Polygon/MultiPolygon을 사용하며 사각형으로 판정하지 않는다. 섬과 영역의 구멍도 유지한다. 현재 지역을 선택하는 웹 지도용 경계이며, 재생 월의 과거 행정구역 복원이나 신고 통계의 공간 재분류에 쓰지 않는다.

약 696KB인 로컬 경계 파일은 한 번 받는다. 원본 commit·라이선스·변경 내역·SHA-256과 재생성 방법은 [경계 파일 안내](../frontend/public/data/README.md)에 있다. 일반 빌드와 브라우저는 원본 저장소를 조회하지 않는다. 경계 로드 실패 시 재시도를 제공하며 하단 지역 목록은 계속 사용할 수 있다.

## 검증

- 경계 16개, SHA-256, 폐합 링·WGS84 좌표, 16지역 실제 도시 표본 검사
- 서울/경기 중첩 사각형의 구멍, 바다 비선택, 제주 추자도, 대구 군위 이전 검사
- 기존 로더의 스트림·ID 보존·부분 파일 거부·취소 검사 포함 6개 테스트 통과
- 브라우저: 경남→부산 클릭 후 약국·3개월·2020-06 유지, 통계 갱신, 사업장 점 상세 조회, 테마 전환
- 드래그 중 부산 선택 유지, 경남 호버 강조·지역명 안내 확인
- 390×844 화면: 부산→경남 터치 선택, 가로·세로 넘침 없음

명령: `frontend`에서 `node --test src/regionBoundaries.test.mjs src/nationalPlaybackData.test.mjs`, `npm run build`, `npm run lint`. 빌드·lint 통과, 기존 번들 크기 경고는 남아 있다.

[경남 선택 상태에서 부산 호버 안내 검증 화면](data-samples/national/region-map-selection-browser.jpg). 화면 크기 변경과 지역 선택이 연속으로 일어나도 실제 지도 크기를 갱신한 뒤 선택 지역에 맞춘다.
