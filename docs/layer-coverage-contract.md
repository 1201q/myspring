# 레이어 제공 범위 공통 메타데이터 규격

작성일: 2026-11-23. [현재 현황](layer-coverage-inventory.md)을 기반으로 한 후속 구현 규격 v1이다. 이 문서의 필드와 판정 함수는 아직 런타임에 도입하지 않았다.

## 기본 원칙

전국 공통 원천을 우선하되 지역 전용 데이터도 독립적으로 제공한다. 원천의 전국 제공 안내, 실제 확보 범위, 검증 결과, 서비스 발행 범위를 구분한다. 파일 존재나 수록 건수만으로 전수성을 판단하지 않는다.

레이어는 화면의 표현 단위이고 데이터셋은 동일한 정의·원천·버전의 자료 단위다. 하나의 레이어가 여러 지역 데이터셋을 선택할 수 있다. 지자체별 정의가 다르면 렌더러를 공유해도 데이터셋과 범례·설명을 분리한다. 같은 시설의 전국 원천과 지역 원천을 함께 사용할 때는 대체 범위 또는 중복 제거 규칙을 검증한 뒤 합친다.

## 메타데이터 구조

| 단위 | 필수 정보 | 용도 |
| --- | --- | --- |
| LayerDefinition | `id`, `label`, `datasetIds`, `metricIds` | UI 레이어와 사용 가능한 데이터셋·지표 연결 |
| DatasetDefinition | `id`, `version`, `source`, `subject`, `geometryTypes`, `timeMode`, `areaMappings`, `coverageEntries` | 원천별 의미·시간·공간 조건 |
| source | 기관, 원천 URL, 원천 ID, 원천 제공 범위 안내, 이용 조건과 확인 상태, 수집일, 원본 해시 | 원천의 존재와 배포 가능성을 별도로 확인 |
| subject | 대상 시설·통계 정의, 포함·제외 대상, 단위 | ‘주요상권’과 ‘모든 상권’, 세대와 가구 등의 혼동 방지 |
| areaMappings | 서비스 지역 ID, 원천 코드·코드 체계·버전, 공간 교차 범위, 대응 근거 | 강원·전북 구/신 코드, 광주·전남 합성 지역, 철도 권역 대응 |
| CoverageEntry | 지역, 하위 지역/공간 마스크, 기간 또는 기준시점, 지표/하위 유형, 확보 단계, 제공 상태, 수록 완전성, 사유·근거 | 실제 선택 조건별 제공 판정 |

`CoverageEntry`에는 다음 항목을 둔다.

| 필드 | 값과 규칙 |
| --- | --- |
| `datasetVersion` | 같은 버전의 파일·감사 결과만 연결 |
| `regionId`, `sourceAreaCodes` | 서비스 ID와 원천 코드를 함께 보존. 코드 문자열만으로 자동 변환하지 않음 |
| `spatialScope` | 수록 시군구 코드 또는 마스크 참조. 확인되지 않은 지역 내부 범위를 임의 추정하지 않음 |
| `metricId`, `subtypeId` | 인구 수/전월 증감, 트렌드 6종 등. 전체 적용은 명시적인 `all` 사용 |
| `timeMode` | `snapshot` / `series` / `validity` |
| `referencePeriod` | 스냅샷 기준일·월·분기와 정밀도. 2023-Q1을 임의의 일자로 바꾸지 않음 |
| `periods` | 실제 제공 월·연도 목록 또는 구간 목록과 결측 목록. 시작·끝만으로 중간 연속성을 추정하지 않음 |
| `stage` | `discovered` / `acquired` / `verified` / `published`. 해당 버전의 처리 단계이며 운영 배포 상태와 별개 |
| `availability` | `available` / `partial` / `unavailable` / `unknown`. 해당 지역·기간·지표에서 서비스가 표시 가능한 범위 |
| `completeness` | `complete` / `partial` / `unknown`. 명시된 대상·공간·시점에 대한 수록 완전성. `complete`에는 전수성을 뒷받침하는 근거 필수 |
| `reasonCode`, `notice` | 미발행, 부분 지역, 기간 밖, 경계 미대응, 비교 월 없음, 주제 미수록, 검증 미완료 등의 기계용 사유와 사용자 설명 |
| `counts` | 원본 행·유효 좌표·표시 가능 행·중복 수. 경계 대응은 분자·분모와 그 의미를 명시. 모르는 값은 `null` |
| `evidence`, `checkedAt` | 감사 파일·manifest·문서의 참조와 확인일. 다른 브랜치는 커밋과 저장소 경로로 고정 |
| `artifact` | `published`일 때 파일 경로·해시 또는 API 발행 버전. 범위 판정 후에만 요청 |

필수 필드가 빠지거나 버전·근거가 충돌하면 발행 검증에서 실패시킨다. 등록되지 않은 조합은 `unknown`으로 판정하며 0건 자료를 생성하지 않는다.

`availability=available`은 정의된 수록 범위의 자료를 표시할 수 있다는 뜻이다. 예를 들어 선정 36개 노선은 표시 가능해도 전국 모든 철도를 포함하지 않는다. `completeness`와 대상 설명을 함께 노출한다. 행이 0개인 발행본도 존재할 수 있지만, 검증된 수록 대상 목록의 0건인지 자료 미확보인지 근거로 구분한다.

## 제공 판정과 화면 동작

판정 입력은 `layerId`, 서비스 지역, 시군구 필터, 선택 기간, 지표·하위 유형이다. 출력은 제공 상태, 실제 적용 공간·기간, 선택된 데이터셋 버전과 파일, 출처·기준일·안내다.

1. 레이어의 후보 데이터셋 중 선택 지역·대상 정의에 맞는 자료를 찾는다. 여러 자료가 겹치면 명시된 우선순위·대체 범위·중복 제거 규칙을 적용한다. 규칙이 없으면 합산하지 않는다.
2. 실제 발행 단계와 공간 교차 범위를 확인한다. 연구에서 원천이 발견됐어도 미발행이면 서비스에서는 비활성화하고 ‘자료 준비 전’으로 안내한다.
3. 시간 모드와 지표의 필요 조건을 확인한다. 통계가 전월을 요구하면 이전 월도 제공돼야 한다. 일부 월·시군구만 표시 가능하면 `partial`과 정확한 범위를 반환한다.
4. 판정 결과에 따라 파일을 지연 로딩한다. 로딩·네트워크·형식 오류는 별도 `loadState`로 처리하고 제공 상태를 미제공으로 덮어쓰지 않는다.

| 판정 | 레이어 선택 화면 | 지도·정보 패널 |
| --- | --- | --- |
| `available` | 선택 가능, 수록 대상·기준일 표시 | 검증된 범위 렌더링. 완전성 미확인이면 함께 안내 |
| `partial` | 선택 가능, ‘일부 지역/기간 제공’ | 제공 범위·누락 사유 표시. 누락 영역은 결측으로 표현 |
| `unavailable` | 해당 조건에서 비활성화, 사유 표시 | ‘선택 기간 자료 없음’, ‘현재 경계 대응 불가’ 등 구체 안내 |
| `unknown` | ‘제공 범위 확인 중’으로 비활성화 | 시설 없음·0건·통계 0으로 표시하지 않음 |
| 로딩 실패 | 재시도 가능 | 오류와 재시도 표시. 제공 범위 판정은 유지 |

미제공 레이어도 목록에서 이유를 확인할 수 있게 한다. 사용자의 켜기 선택과 현재 조건에서 실제 표시 가능한 상태를 분리한다. 지역·기간을 바꾸면 즉시 재판정하고 이전 지역의 지도·통계는 숨긴다. 제공 가능한 조건으로 돌아오면 기존 켜기 선택에 따라 다시 표시한다.

## 시간 모드

- `snapshot`: 상권 경계·상권 길·현재 철도 같은 기준시점 고정 자료. 과거 개폐업과 함께 볼 수 있으나 기준시점을 항상 표시하고 과거 당시 시설이라고 설명하지 않는다.
- `series`: 월간 인구 등의 실제 시계열. 선택 기간의 마지막 월, 기간 합계 등 지표별 조회 규칙을 명시한다. 범위 밖을 최신값으로 대체하거나 결측을 보간하지 않는다.
- `validity`: 실제 유효 시작·종료가 검증된 시설만 선택 시점과 교차 판정한다. 준공일·설립일·포털 수정일만으로 이 모드를 부여하지 않는다.

수집일, 자료 기준일, 포털 수정일, 검증일, 서비스 발행일은 별도 값이다. 원천의 기준일이 행별로 다르면 최소·최대 및 혼재 사실을 보존한다.

## 지역별 원천 조사·채택 절차

1. 전국 공통 원천의 대상 정의·제공 지역·시간·도형·조건을 확인한다.
2. 실제 파일/API 응답을 확보해 시군구별 수록·좌표·중복·날짜·결측을 검사한다. 전국이라는 제목만으로 전수 판정하지 않는다.
3. 부족한 지역은 지자체 원천을 확인하고 같은 의미로 비교할 수 있는지 검증한다. 점 위치만 있으면 실제 경계나 도로 형상으로 변환하지 않는다.
4. 동일 정의면 지역별 데이터셋을 같은 레이어에 연결한다. 의미가 다르면 하위 유형 또는 별도 레이어로 제공한다. 서로 다른 정의의 수치를 지역 순위로 직접 비교하지 않는다.
5. 확인한 이용 조건, 실제 파일, 감사 결과와 제공 범위를 함께 발행한다. 조건이 미확정이면 조사·로컬 확보와 서비스 제공 승인을 구분해 미확정 상태를 남긴다.

## 후속 구현의 완료 기준

- 전남광주 인구 2026-06은 현재 경계 대응 불가, 2026-07은 대응 가능으로 판정한다.
- 경기 2026-10은 인구 경계 대응 601/602의 부분 제공을 표현한다.
- 2025-10 인구 수와 전월 증감의 제공 상태가 다르다.
- 전국 원천이 없는 가상의 지역 전용 데이터셋도 등록된 지역에서만 선택 가능하다.
- 주요상권·상권 길의 강원/전북 코드 차이와 광주·전남 병합 매핑을 보존한다.
- 스냅샷은 과거 재생 중에도 기준시점을 안내하며, 시계열은 기간 밖 값을 대체하지 않는다.
- 미확인·미제공·결측·검증된 0건·로딩 실패를 구분한다.
- 지역 전환 때 이전 자료가 남지 않으며, 부분 제공 결과의 합계를 지역 전체 통계로 표시하지 않는다.

현재 `LayerState`의 boolean은 사용자의 켜기 선택으로 유지할 수 있다. 데이터셋 카탈로그·범위 판정·로딩 상태를 분리해 추가하고, 기존 렌더러와 수집기는 단계적으로 연결한다.
